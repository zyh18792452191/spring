## 1. 目标与范围

### 1.1 一句话定位
策略中心是营销活动全流程中枢，覆盖 **洞察接收 → 策略制定 → 活动配置 → 调度派发 → 效果评估 → 沉淀复用** 的端到端闭环。

### 1.2 七大功能模块
| # | 模块 | 现有/新建 | 主要页面 |
|---|---|---|---|
| 5 | 策略中心门户 | 部分现有 | 策略总览、剧本营销 |
| 6 | 策略制定工作流 | 部分现有 | 接收诊断、策略匹配、策略调度 |
| 7 | 活动配置 | 部分现有 | IOP 普通营销、网格通、剧本营销 |
| 8 | 策略管理 | 现有 | 根因库、策略库、关联关系 |
| 9 | 策略沉淀 | 新建 | 效果库、最佳实践、策略版本、模板 |
| 10 | 跨中心协作 | 新建 | 与洞察/调度/评估/知识中心接口 |
| 11 | 评估中心 | 现有 | 区域评估、工单改善、策略评估摘要 |

### 1.3 非目标
- 不实现后端真实 API，所有数据走前端 mock + Supabase migration 占位。
- 不实现细粒度 RBAC（见 §15 建议清单）。
- 不做移动端适配（PC 优先，最小宽度 1280）。

## 6. 策略制定工作流

### 6.1 接收诊断（新建）
**路由**：`/workspace/insight` 或 `/portal/strategy/diagnose`
**源文件**：新建

**目的**：从洞察中心接收诊断结论（指标异常 → 根因 → 建议），作为策略制定的输入。

**布局**：
```
[指标搜索框] [业务场景] [时间范围] [接收方式]      ← 顶部筛选
┌────────────────────────────────────────────────┐
│  诊断结论列表（Table，可分页，PAGE_SIZE=15）    │
└────────────────────────────────────────────────┘
[批量制定策略] [导出]                              ← 底部操作
```

**Table 列**：
| 列 | 字段 | 说明 |
|---|---|---|
| □ | selected | Checkbox，多选 |
| 指标名称 | indicatorName | Link，点击跳到 §6.2 策略匹配 |
| 业务场景 | businessScenario | 流量运营/离网维系/... |
| 当前值 | currentValue | 数字 + 单位 |
| 基期值 | baseValue | 数字 + 单位 |
| 目标值 | targetValue | 数字 + 单位 |
| 达成率 | achievementRate | 公式：`(currentValue - baseValue) / (targetValue - baseValue) × 100%`，健康度颜色 ≥80 绿/60-79 黄/<60 红 |
| 异常原因 | rootCause | 文本（来自根因库匹配） |
| 建议策略数 | strategyCount | 数字 |
| 接收时间 | receivedAt | yyyy-MM-dd HH:mm |
| 状态 | status | 待处理/已制定/已忽略 |
| 操作 | — | [去制定] [忽略] |

**交互**：
- 顶部 [批量制定策略]：把选中行的诊断结论打包传入 §6.2 策略匹配页（带 `?from=insight&ids=...`）。
- 行 [去制定]：单行跳转。

function getValidityStatus(item: Strategy) {
  if (item.status === '下架' && !item.validFrom) return '未上架';
  const diffDays = Math.ceil((+new Date(item.validUntil) - Date.now()) / 86400000);
  if (diffDays < 0) return '已过期';      // 红
  if (diffDays <= 30) return '即将过期';  // 黄
  return '有效';                            // 绿
}

        <TableCell>{row.xxx}</TableCell>
      </TableRow>
    ))}
  </TableBody>
</Table>
```

**分页**：底部 `<Pagination page={page} pageSize={15} total={total} onChange={setPage} />`

### 13.3 弹窗（Dialog）
- 标题：左对齐 + 主色图标（可选）
- 内容：`p-6`
- 底部：`border-t border-gray-200`，右对齐按钮
- 默认宽度：`max-w-2xl`（普通）/ `max-w-4xl`（复杂表单）

### 13.4 多标签页（TabsBar）
工作台内可同时打开多个子页面，每个 Tab 显示标题 + 关闭按钮。

  ]}
  activeTab={activeTab}
  onClose={onCloseTab}
  onSelect={onSelectTab}
/>
```

### 13.5 可视化编辑器（PageEditor）
- 触发：URL 加 `?editor=true` 或按 `Ctrl+Shift+E`
- 模式：点击任意元素 → 右侧属性面板修改文本
- 保存：右下角浮窗 [保存] [取消]
- 退出：再次 `Ctrl+Shift+E` 或 [退出编辑]

- 拖动时显示半透明占位，原位置出现虚线框
