## 1. 产品概述

### 1.1 产品定位

AI洞察助手是市场数智运营平台的**智能分析引擎**，面向新疆移动省公司及16地市分公司的运营人员，提供从数据到洞察的一站式分析能力。用户通过自然语言描述需求，AI自动完成数据采集、分析推理、洞察提炼和报告生成全流程。

### 1.2 目标用户

| 角色 | 典型场景 | 高频操作 |
|------|---------|---------|
| 省公司分析师 | 月度经营分析报告、全疆指标异动分析 | 从模板创建报告、指标异动归因 |
| 地市运营人员 | 本地市流量运营分析、离网预警分析 | 从零创建报告、数据集上传分析 |
| 网格长 | 网格级客户分析、攻坚作战报告 | 快速生成数据摘要、看板 |
| 业务管理者 | 审阅团队报告、查看关键洞察 | 审阅追问、共享可见性设置 |

### 1.3 核心价值主张

- **零门槛分析**：自然语言描述需求，无需写SQL、无需拖拽
- **4种产出形态**：洞察报告、数据报表、数据看板、数据摘要，覆盖不同分析场景
- **平台数据直连**：指标/指标树/客群/数据集/报表5类数据源，无需手动导入
- **模板复用**：AI创建/手动创建/历史提取3种模板来源，标准化报告结构
- **组织级共享**：归档时设置可见性，团队内知识流通

## 2. 使用场景推演

### 场景1：月度经营分析报告 — 从模板创建

**角色**：张敏，省公司经营分析专员，每月5号需要提交月度经营分析报告。

> 7月5日一早，张敏打开市场数智运营平台，进入AI洞察助手。点击"洞察报告"快捷入口卡片，AI欢迎语弹出。张敏输入"生成本月经营分析报告"。
>
> AI理解需求后，引导张敏选择数据源。张敏点击"平台指标"按钮，在弹窗中搜索"大市场"，勾选"大市场关键指标体系"和"大市场重点指标体系"，点击确定。右侧面板展示已选的2个指标体系。
>
> 张敏选择账期：月度→2026年6月，点击"确认数据"。
>
> 由于选择的是报告类型，AI自动进入大纲确认阶段。右侧面板展示从模板提取的报告大纲：8个章节（整体经营概况、收入分析、客户分析、流量分析、5G发展、宽带业务、渠道效能、风险预警）。张敏浏览大纲，觉得风险预警章节需要加入"ARPU异动"子节，输入"在风险预警下加一个ARPU异动分析"。AI修改大纲并展示更新。
>
> 张敏确认大纲，AI进入报告生成阶段。4步过程（数据采集→数据校验→分析引擎→报告构建）逐条展示进度。约2分钟后，报告生成完毕，右侧预览区展示完整报告。
>
> 张敏逐章阅读，发现"收入分析"中缺少同比数据，追问"收入分析的同比数据加上"。AI补充同比数据，更新报告内容。
>
> 张敏满意后点击归档，弹窗展示可见性设置。张敏选择"本区域"（省公司全员可见），确认归档。报告自动出现在下载专区"团队"Tab中，省公司其他分析师登录即可查看。

**实现状态**：✅ 已实现

## 4. AI洞察助手 — 完整业务逻辑

### 4.1 生成类型

用户可生成4种类型的分析产出物，在对话初始通过快捷入口卡片或自然语言设定：

| 生成类型 | 标识 | 产出形态 | 导出格式 | 是否需要大纲确认 |
|----------|------|---------|---------|----------------|
| 洞察报告 | report | 结构化多章节报告 | Word/PDF | ✅ 需要 |
| 数据报表 | spreadsheet | 行列数据表 | Excel/CSV | ❌ 跳过 |
| 数据看板 | dashboard | KPI卡片+图表组合 | 在线链接/PDF截图 | ❌ 跳过 |
| 数据摘要 | summary | 关键发现编号列表 | 文本/PDF | ❌ 跳过 |

**默认值**：report（洞察报告）

**设定方式**：
- 点击快捷入口卡片（4个卡片分别对应4种类型）
- 在对话中自然语言描述（如"生成一份Excel报表"→自动识别为spreadsheet）

### 4.2 步骤流转状态机

```
需求收集 ──→ 数据准备 ──→ 大纲确认 ──→ 产出物生成 ──→ 追问深化 ──→ 已归档
  (1)          (2)      (仅report)      (3)          (4)        (5)
                                                    ↑    ↓
                                                    └────┘ 可循环追问
```

**各步骤详细逻辑**：

#### 步骤1：需求收集

- **触发条件**：用户发送第一条消息
- **AI行为**：理解用户需求，自动推进到数据准备阶段（无"确认需求"按钮）
- **用户操作**：描述分析需求，如"分析乌鲁木齐6月ARPU下降原因"
- **快捷入口**：4个入口卡片（洞察报告/数据报表/数据看板/数据摘要），点击即设定generationType并发送提示语
- **退出条件**：AI理解需求后自动推进

#### 步骤2：数据准备

- **触发条件**：AI自动推进，或用户从需求收集阶段自然过渡
- **右侧面板展示**：
  - 已选数据源列表（每项可删除，底部"清空全部"按钮）
  - 账期选择器（选择数据集时自动隐藏）
  - 数据概要（数据源数量/类别/覆盖范围/分析账期）
  - "确认数据"按钮
- **数据按钮区**：6个按钮（根据条件显示）
  - 选择数据集
  - 平台指标
  - 指标树
  - 选择客群
  - 选择报表
  - 上传报告模板（仅report类型+模板未确认时显示）
- **数据确认后**：数据源按钮变为不可点击（dataConfirmed=true）
- **退出条件**：点击"确认数据"按钮

**数据源类别互斥规则**（CRITICAL）：

5类数据源（indicator/tree/group/dataset/report）为**五选一**关系：
- 选择任一类别后，其他类别的选择项灰显不可点
- 类别内可多选（如选3个指标体系）
- 清空已选数据源后可重新选择类别
- 互斥判断依据：`dataSourceCategory`状态值

**账期选择器**：

| 账期类型 | 选择控件 | 默认值 |
|---------|---------|--------|
| 日度 | 年+月+日三个下拉 | 当天 |
| 月度 | 年+月两个下拉 | 当月 |
| 季度 | 年+季度两个下拉 | 当季 |
| 半年 | 年+上下半年两个下拉 | 当前半年 |
| 年度 | 年一个下拉 | 当年 |

**数据集与账期的关系**（CRITICAL）：
- 选择数据集时，账期选择器自动隐藏
- 原因：数据集是用户上传的原始数据，时间信息已包含在数据本身中
- 数据概要中展示"数据集自带账期：{dataTimeRange}"（从数据源管理模块获取）

**基于模板生成**：
- 仅generationType=report时展示模板选择入口（templateSelect组件）
- 模板选择3种方式：从已归档报告选择 / 从模板库选择（弹窗） / 上传报告模板（Word/PDF）
- 模板确认后（templateConfirmed=true），数据按钮区不再展示"上传报告模板"，只展示5个数据源按钮
- 用户可"跳过模板选择，直接开始"→设置templateConfirmed=true，不选模板
- 用户说"换模板"/"重新选择模板"→重置templateConfirmed=false

#### 步骤3：大纲确认（仅report类型）

- **触发条件**：确认数据后，generationType=report时自动进入
- **非report类型**：跳过此步骤，确认数据后4秒自动推进到追问深化
  - spreadsheet：AI提示"自动识别指标与维度/生成数据透视表/计算同环比"
  - dashboard：AI提示"布局4宫格/图表：趋势图+对比柱图+占比饼图+指标卡"
  - summary：AI提示"提取关键发现/识别异常指标/生成行动建议"
- **右侧面板展示**：章节结构树（从模板提取或AI生成）
- **快捷按钮**："确认大纲"按钮
- **用户操作**：可在对话中修改大纲（增加/删除/调整章节）
- **退出条件**：点击"确认大纲"按钮

#### 步骤4：产出物生成

- **触发条件**：报告类型=确认大纲后；非报告类型=确认数据4秒后
- **右侧面板展示**：4步进度条
  1. 数据采集（completed）→ 日志：已获取XX个核心指标数据
  2. 数据校验（running→completed）→ 日志：数据完整性校验通过/口径一致性校验通过
  3. 分析引擎（waiting→running→completed）→ 日志：启动因果推理/执行归因分析/趋势预测
  4. 报告构建（waiting→running→completed）→ 日志：生成各章节/整合报告结构/报告生成完成
- **每步约1秒间隔自动推进**
- **快捷按钮**：此阶段无快捷按钮
- **退出条件**：4步全部完成后自动推进到追问深化

#### 步骤5：追问深化

- **触发条件**：产出物生成完毕后自动进入
- **快捷按钮**："归档"按钮
- **导出按钮**：DropdownMenu"导出为▼"，动态过滤只显示当前类型对应格式
  - report → Word / PDF
  - spreadsheet → Excel / CSV
  - dashboard → 在线链接 / PDF截图
  - summary → 文本 / PDF
- **用户操作**：
  - 继续追问：AI基于已有报告上下文补充分析
  - 归档：点击"归档"按钮
  - 导出：选择格式下载
- **软对话意图识别**：AI根据关键词匹配用户意图
  - 换数据/重新选择数据/换指标 → 提示"创建新对话重新选择"
  - 回到需求/重来 → 提示"创建新对话重新开始"
  - 操作指引/怎么导出/怎么归档 → 给出操作步骤
  - 其他 → 正常追问分析

**退出条件**：点击"归档"按钮

#### 步骤6：已归档

- **触发条件**：归档弹窗确认后
- **输入框**：禁用，placeholder="已归档，点击重新打开继续编辑"
- **快捷按钮**：
  - "重新打开" → 恢复到追问深化阶段
  - "导出为▼" → 同追问深化阶段的导出
  - "前往下载" → router.push跳转下载专区AI洞察Tab
- **产出物存储**：
  - 归档时写入localStorage的`ai-insight-archived-outputs`公共key
  - 下载专区读取此key展示真实归档数据
- **可见性**：归档时设置，持久化到ConversationState

## 6. 模板管理

### 6.1 功能定位

模板管理定义报告的**章节结构**，是纯结构定义，不涉及指标关联和数据源绑定（数据绑定在AI洞察助手报告生成时完成）。

### 6.2 模板来源

| 来源 | 标识 | 入口 | 说明 |
|------|------|------|------|
| AI创建 | ai | /templates/ai-create | AI对话+右侧章节编辑，独立页面 |
| 手动创建 | manual | /templates/edit | 手动编辑章节结构，独立页面 |
| 历史报告提取 | extract | /templates/extract | 从历史报告提取章节结构 |

**入口视觉层级**：
- AI创建：主色实心按钮（推荐，最突出）
- 从历史报告提取：Ghost按钮（次级）
- 手动创建：文字链接（最弱）

### 6.3 模板字段

| 字段 | 说明 | 数据来源 |
|------|------|---------|
| 模板名称 | 模板标题 | 人工录入/AI生成 |
| 来源 | AI创建/手动创建/历史报告提取 | 系统自动标记 |
| 标签 | 分类标签（多选） | 人工选择 |
| 章节结构 | 多级嵌套章节+段落 | 人工编辑/AI生成/历史提取 |
| 章节数 | 总章节数（含子章节） | 系统自动计算 |
| 更新时间 | 最后修改时间 | 系统自动记录 |

### 6.4 章节结构

**递归结构，支持无限层级**：

```
TemplateSection {
  id: string
  title: string           // 章节标题
  children?: TemplateSection[]  // 子章节（递归）
  paragraphs?: Paragraph[]     // 段落列表
}

Paragraph {
  type: 'text' | 'table' | 'chart' | 'analysis'  // 段落类型
  label: string          // 段落标签（如"趋势分析"、"数据表格"）
  description?: string   // 段落描述
}
```

**注意**：段落不包含"关联指标"和"数据来源"字段。模板是结构定义，指标和数据源在报告生成时通过AI洞察助手选择和绑定。

### 6.5 AI对话创建模板页面（/templates/ai-create）

- **布局**：左侧对话区 + 右侧章节编辑区
- **流程**：
  1. 用户在对话区描述报告结构需求
  2. AI生成章节结构，展示在右侧编辑区
  3. 用户可在右侧编辑区直接调整章节（添加/删除/重命名子章节、添加段落）
  4. 设置模板名称和标签
  5. 保存到模板库

### 6.6 手动创建模板页面（/templates/edit）

- 递归SectionEditor组件
- 每级章节可：添加子章节、添加段落（4种类型）、删除
- depth参数控制缩进和背景色递进

### 6.7 从历史报告提取模板页面（/templates/extract）

- 历史报告列表：搜索+标签筛选+分页（8条/页）
- 列表项展示：报告名称、标签Badge、章节数、更新时间
- 点击报告→提取章节结构→进入编辑页面

### 6.8 模板详情

- 展示：标签、来源、关联报告数、创建时间、章节结构树
- 不展示"使用此模板创建报告"按钮（入口归一到AI洞察助手）
- 不展示"数据需求"section（模板不涉及数据绑定）
