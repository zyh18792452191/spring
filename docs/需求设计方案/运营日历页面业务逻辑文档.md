# 运营日历页面业务逻辑文档

## 1. 页面概述

运营日历页面是一个多视图的任务管理系统，用于可视化和运营任务的调度与管理。页面支持**列表视图**和**日历视图**两种主要展示模式，日历视图下又包含**日历模式**和**月历模式**。

---

## 2. 视图切换

### 2.1 主视图切换（列表视图 ↔ 日历视图）

| 视图 | 描述 | 适用场景 |
|------|------|----------|
| **列表视图** | 以表格形式展示任务列表，支持详细筛选和批量操作 | 需要查看任务详情、批量管理时 |
| **日历视图** | 以日历/月历形式展示任务分布，支持时间维度可视化 | 需要查看任务时间分布、规划调度时 |

### 2.2 日历视图子模式（日历模式 ↔ 月历模式）

仅在**日历视图**下可用：

| 模式 | 描述 | 数据范围 | 右侧活动列表 |
|------|------|----------|--------------|
| **日历模式** | 展示单个月份的日期网格 | 当月活动 | 近一周活动 |
| **月历模式** | 展示全年12个月的缩略视图 | 本年活动 | 近一月活动 |

## 3. 列表视图业务逻辑

### 3.1 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 运营任务名称 | 文本输入 | 模糊搜索任务名称，支持回车触发搜索 |
| 创建人 | 文本输入 | 按创建人筛选，支持回车触发搜索 |
| 状态 | 下拉选择 | 全部/未开始/进行中/已结束/已下线 |
| 区域 | 下拉选择 | 全国/各省级行政区 |

### 3.2 操作按钮

| 按钮 | 功能 | 显示条件 |
|------|------|----------|
| 搜索 | 执行筛选查询 | 始终显示 |
| 重置 | 清空所有筛选条件 | 始终显示 |
| 导出 | 导出当前筛选结果 | 仅列表视图显示 |
| 新建任务 | 创建新的运营任务 | 始终显示 |

### 3.3 任务状态与操作权限

| 状态 | 可用操作 |
|------|----------|
| 未开始 | 详情、编辑、素材管理、删除 |
| 进行中 | 详情、下线 |
| 已结束 | 详情、调整实际结束时间、删除 |
| 已下线 | 详情、删除 |

## 4. 日历视图业务逻辑

### 4.1 筛选条件

#### 4.1.1 日历模式筛选

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 年份选择 | 下拉选择 | 2020-2029年 |
| 月份选择 | 按钮组 | 1-12月快速切换 |
| 省份筛选 | 下拉选择 | 全部/全国/各省级行政区 |
| 任务筛选 | 搜索+下拉 | 搜索任务名称并选中特定任务 |
| 今天/本月 | 快捷按钮 | 快速跳转到当前时间 |

#### 4.1.2 月历模式筛选

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 年份选择 | 下拉选择 | 2020-2029年 |
| 省份筛选 | 下拉选择 | 全部/全国/各省级行政区 |
| 任务筛选 | 搜索+下拉 | 搜索任务名称并选中特定任务 |
| 本月 | 快捷按钮 | 快速跳转到当前月份 |

### 4.2 日历模式数据展示

#### 4.2.1 日期网格

- **今日标识**：当天日期显示蓝色边框和"今天"标签
- **任务显示**：
  - 每个日期最多显示3个任务
  - 超出部分显示"更多N条"链接
- **选中任务高亮**：
  - 选中特定任务后，日历中该任务跨越的所有日期显示蓝色背景
  - 开始日期：左侧蓝色边框
  - 结束日期：右侧蓝色边框
  - 中间日期：纯蓝色背景
  - 单日任务：左右蓝色边框

#### 4.2.2 活动统计

| 统计项 | 说明 |
|--------|------|
| 本月活动数 | 当前月份的任务总数 |
| 本月进行中活动 | 状态为"进行中"的任务数 |
| 本月已结束活动 | 状态为"已结束"的任务数 |

#### 4.2.3 日期点击交互

点击日期单元格：
1. 打开当天活动弹窗
2. 显示该日期所有任务列表（分页展示）
3. 每个任务支持：详情、编辑、删除、下线操作

### 4.3 月历模式数据展示

#### 4.3.1 月份卡片

- **本月标识**：当前月份显示蓝色边框
- **活动数量**：右上角显示该月活动数量
- **任务预览**：
  - 每个月份最多显示3个任务
  - 超出部分显示"还有N个活动..."
- **选中任务高亮**：
  - 选中任务后，其他月份卡片透明度降低
  - 包含选中任务的月份显示黄色背景

#### 4.3.2 活动统计

| 统计项 | 说明 |
|--------|------|
| 本年活动数 | 当前年份的任务总数 |
| 本年进行中活动 | 状态为"进行中"的任务数 |
| 本年已结束活动 | 状态为"已结束"的任务数 |

#### 4.3.3 月份点击交互

点击月份卡片：
1. 打开月份活动弹窗
2. 显示该月所有任务列表（分页展示）
3. 每个任务支持：详情、编辑、删除、下线操作

## 5. 右侧活动列表

### 5.1 数据范围

| 视图模式 | 数据范围 | 说明 |
|----------|----------|------|
| 日历模式 | 近一周活动 | 当前日期前后7天内的任务 |
| 月历模式 | 近一月活动 | 当前日期前后30天内的任务 |

### 5.2 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 任务名称 | 文本输入 | 模糊搜索任务名称 |
| 状态 | 下拉选择 | 全部/未开始/进行中/已结束 |
| 重置 | 按钮 | 清空筛选条件 |
| 搜索 | 按钮 | 执行搜索 |

### 5.3 任务卡片展示

每个任务卡片包含：
- **任务名称**：单行显示，超长截断
- **计划时间**：开始日期 ~ 结束日期
- **实际结束时间**：如有则显示
- **所属省份**：标签形式展示
- **状态标签**：不同状态显示不同颜色
  - 未开始：灰色
  - 进行中：绿色
  - 已结束：橙色
  - 已下线：灰色

### 5.4 任务选中联动

点击右侧活动列表中的任务卡片：
1. 设置为选中任务
2. 日历/月历中高亮显示该任务的时间跨度
3. 卡片显示蓝色边框选中状态
4. 活动统计区域切换为显示选中任务的详细信息

### 5.5 操作权限

| 状态 | 可用操作 |
|------|----------|
| 未开始 | 详情、编辑、删除 |
| 进行中 | 详情、下线 |
| 已结束 | 详情、编辑、删除 |

---

## 6. 筛选联动规则

### 6.1 主筛选区与右侧活动列表联动

| 主筛选项 | 联动影响 |
|----------|----------|
| 省份筛选 | 同时影响日历数据和右侧活动列表 |
| 任务筛选 | 仅影响日历高亮显示，不影响右侧列表 |

### 6.2 日历/月历模式切换联动

| 切换场景 | 数据刷新 | 右侧列表范围 |
|----------|----------|--------------|
| 日历 → 月历 | 重新加载年度数据 | 切换为近一月活动 |
| 月历 → 日历 | 重新加载月度数据 | 切换为近一周活动 |

### 6.3 年份/月份切换

| 操作 | 数据刷新 | 右侧列表影响 |
|------|----------|--------------|
| 切换年份 | 重新加载对应年度数据 | 无影响 |
| 切换月份（日历模式） | 重新加载对应月度数据 | 无影响 |

## 7. API接口说明

### 7.1 日历数据接口

```
GET /api/operational-tasks/calendar
```

**参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| year | number | 是 | 年份 |
| month | number | 条件 | 月份（日历模式必填） |
| province | string | 否 | 省份筛选 |

**返回：**
```typescript
{
  success: boolean;
  data: {
    tasks: OperationalTask[];
    statistics: {
      totalCount: number;
      inProgressCount: number;
      finishedCount: number;
    };
  };
}
```

### 7.2 近期活动接口

```
GET /api/operational-tasks/recent
```

**参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| days | number | 是 | 天数范围（7或30） |
| page | number | 是 | 页码 |
| pageSize | number | 是 | 每页条数 |
| taskName | string | 否 | 任务名称搜索 |
| status | string | 否 | 状态筛选 |
| province | string | 否 | 省份筛选 |

**返回：**
```typescript
{
  success: boolean;
  data: OperationalTask[];
  total: number;
}
```

### 7.3 任务列表接口

```
GET /api/operational-tasks
```

**参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | number | 是 | 页码 |
| pageSize | number | 是 | 每页条数 |
| taskName | string | 否 | 任务名称搜索 |
| createdBy | string | 否 | 创建人 |
| status | string | 否 | 状态筛选 |
| province | string | 否 | 省份筛选 |

## 8. 数据结构

### 8.1 任务对象（OperationalTask）

```typescript
interface OperationalTask {
  id: number;
  task_code: string;          // 任务编码
  task_name: string;          // 任务名称
  status: string;             // 状态：not_started/in_progress/finished/offline
  start_time: string;         // 计划开始时间
  end_time: string;           // 计划结束时间
  actual_end_time?: string;   // 实际结束时间（可选）
  duration_days: number;      // 持续天数
  province: string;           // 所属省份
  form_template_id: number;   // 表单模板ID
  form_template_name: string; // 表单模板名称
  form_data: string;          // 表单数据（JSON字符串）
  created_by: string;         // 创建人
  created_at: string;         // 创建时间
  updated_at: string;         // 更新时间
}
```

## 9. 交互流程图

### 9.1 列表视图流程

```
用户进入页面 → 默认列表视图 → 加载任务列表
                          ↓
用户设置筛选条件 → 点击搜索 → 刷新列表
                          ↓
用户点击任务操作 → 详情/编辑/删除等 → 执行对应操作
```

### 9.2 日历视图流程

```
用户切换日历视图 → 加载当前月日历数据 + 近一周活动
                          ↓
用户切换省份筛选 → 同时刷新日历和右侧列表
                          ↓
用户搜索并选中任务 → 日历高亮显示任务时间跨度
                          ↓
用户点击日期 → 弹窗显示当天所有任务
                          ↓
用户切换月历模式 → 加载年度数据 + 近一月活动
                          ↓
用户点击月份卡片 → 弹窗显示当月所有任务
```

## 10. 注意事项

1. **时间处理**：所有日期比较使用字符串格式（YYYY-MM-DD）避免时区问题
2. **分页控制**：
   - 日期弹窗内任务列表分页（每页10条）
   - 月份弹窗内任务列表分页（每页10条）
   - 右侧活动列表分页（每页10条）
3. **性能优化**：
   - 日历模式按月加载数据
   - 月历模式按年加载数据
   - 避免一次性加载大量数据
4. **状态同步**：
   - 省份筛选在日历和右侧列表间同步
   - 任务选中状态在日历和右侧列表间同步
