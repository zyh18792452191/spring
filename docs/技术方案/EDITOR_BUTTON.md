# 可拖动浮动编辑按钮使用指南

## 功能概述

可拖动浮动编辑按钮提供了一个全局、便捷的页面编辑入口，允许用户在任何页面上快速启用/禁用编辑器。

## 特性

### 1. 可拖动
- 按钮可以拖动到页面的任何位置
- 默认位置：页面右下角
- 拖动时按钮保持激活状态

### 2. 点击切换
- 点击按钮启用/禁用编辑器
- 编辑器启用时：
  - 按钮变为蓝色
  - 图标变为 X（关闭）
  - 显示提示文字"拖动移动 | 点击关闭"

### 3. 其他启用方式
除了点击浮动按钮，还可以通过以下方式启用编辑器：
- URL参数：`?editor=true`
- 快捷键：`Ctrl+Shift+E`（Windows/Linux）或 `Cmd+Shift+E`（Mac）

## 使用方法

### 启用编辑器

1. **点击浮动按钮**
   - 找到页面右下角的灰色圆形按钮
   - 点击按钮，按钮变为蓝色，编辑器启用

2. **使用URL参数**
   - 在浏览器地址栏中添加 `?editor=true`
   - 例如：`http://9.129.66.5:5000/portal/market/overview?editor=true`

3. **使用快捷键**
   - 按下 `Ctrl+Shift+E`（Windows/Linux）或 `Cmd+Shift+E`（Mac）
   - 编辑器立即启用

### 禁用编辑器

1. **点击浮动按钮**
   - 再次点击蓝色按钮
   - 按钮变回灰色，编辑器禁用

2. **使用URL参数**
   - 在浏览器地址栏中添加 `?editor=false`
   - 例如：`http://9.129.66.5:5000/portal/market/overview?editor=false`

3. **使用快捷键**
   - 再次按下 `Ctrl+Shift+E` 或 `Cmd+Shift+E`
   - 编辑器禁用

## 编辑器功能

### 元素选择
- 启用编辑器后，点击页面上的任意元素即可选中
- 选中的元素会显示蓝色高亮边框

### 属性编辑
选中元素后，左侧面板显示可编辑的属性：
- **样式**：颜色、字体大小、字体粗细
- **内容**：文本内容
- **布局**：对齐方式、边距、圆角

### 修改记录
- 所有修改都会记录在右侧面板
- 支持查看、清除、导出修改记录
- 点击"保存"按钮将修改写入源代码文件

### 保存修改
1. 在属性面板中进行修改
2. 点击"保存"按钮（右侧面板）
3. 确认保存后，页面自动刷新
4. 修改已写入源代码文件

## 唯一ID系统

每个被编辑的元素都会获得一个唯一的 `data-editor-id` 属性：

- ID格式：`e-xxxxxx`（6位随机字符）
- 在元素首次被选中时自动生成
- 确保修改只影响选中的元素，不会影响其他元素

### 示例

```html
<!-- 编辑前 -->
<div className="card">内容</div>

<!-- 编辑后 -->
<div data-editor-id="e-abc123" className="card" style="color: red;">内容</div>
```

## 注意事项

### 1. 浮动按钮层级
- 浮动按钮的 z-index 为 9999，确保始终显示在页面最上层
- 不会被其他元素遮挡

### 2. 修改保存
- 保存操作会直接修改源代码文件
- 保存后页面会自动刷新以显示更新
- 建议在修改前备份重要文件

### 3. 元素选择
- 编辑器控件（如属性面板、修改记录面板）不会被选中
- 点击这些区域不会触发元素选择

### 4. 持久化
- 编辑器状态会保存到 localStorage
- 刷新页面后编辑器状态保持不变

## 故障排除

### 浮动按钮不显示
- 检查是否使用了 AdBlock 等浏览器插件
- 清除浏览器缓存并刷新页面
- 确认页面加载完成

### 点击按钮无反应
- 检查浏览器控制台是否有错误
- 尝试使用快捷键 `Ctrl+Shift+E`
- 刷新页面后重试

### 修改后页面未刷新
- 检查是否点击了"保存"按钮
- 查看控制台是否有错误信息
- 手动刷新页面（Ctrl+F5 或 Cmd+Shift+R）

### 修改了错误的元素
- 确保选中的元素是目标元素
- 查看修改记录面板中的选择器
- 使用唯一ID确保精确匹配

## 快捷键参考

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+E` / `Cmd+Shift+E` | 切换编辑器状态 |
| `Escape` | 取消选中元素 |
| `Ctrl+S` | 保存修改（在编辑器中） |

## 浏览器兼容性

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

建议使用最新版本的浏览器以获得最佳体验。
