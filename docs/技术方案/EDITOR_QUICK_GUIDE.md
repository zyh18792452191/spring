# 页面编辑器 - 快速使用指南

## 🚀 快速开始

### 1. 启用编辑器

#### 方式一：点击浮动按钮（推荐）
1. 打开任意页面（推荐使用演示页面）
2. 在页面右下角找到灰色圆形按钮（编辑图标）
3. **点击按钮**（不要拖动）
4. 按钮变为蓝色，表示编辑器已启用

**⚠️ 重要提示：**
- 点击和拖动是两个不同的操作
- **点击**：鼠标按下和释放的位置相同，或移动距离小于5像素
- **拖动**：鼠标按下后移动超过5像素再释放
- 只有**点击**会触发编辑器切换，拖动只是移动按钮位置

#### 方式二：URL参数
在浏览器地址栏末尾添加 `?editor=true`
```
http://9.129.66.5:5000/page-editor-demo?editor=true
```

#### 方式三：快捷键
按下 `Ctrl+Shift+E`（Windows/Linux）或 `Cmd+Shift+E`（Mac）

---

### 2. 编辑元素

启用编辑器后：
1. **点击页面上的任意元素** - 元素会被选中，显示蓝色高亮边框
2. **左侧面板** - 显示可编辑的属性：
   - 🎨 **样式**：颜色、字体大小、字体粗细
   - 📝 **内容**：文本内容
   - 📐 **布局**：对齐方式、边距、圆角
3. **修改属性** - 在左侧面板中修改值，立即生效
4. **右侧面板** - 显示所有修改记录

---

### 3. 保存修改

1. 完成所有修改后，点击右侧面板的 **"保存"** 按钮
2. 确认保存对话框
3. 页面自动刷新
4. 修改已写入源代码文件

---

### 4. 禁用编辑器

- 点击浮动按钮（蓝色按钮变为灰色）
- 或按 `Ctrl+Shift+E` / `Cmd+Shift+E`

## 🔍 调试技巧

### 检查编辑器是否启用
打开浏览器控制台（F12），查看日志：
```
EditorWrapper: 切换编辑器状态 { enabled: false, newState: true }
PageEditor: enabled prop 变化 { enabled: true, isEditMode: false }
```

### 检查元素是否被选中
点击元素后，应该看到：
- 元素周围出现蓝色高亮边框
- 左侧显示属性编辑面板

### 检查修改是否记录
在左侧面板修改属性后，右侧面板应该显示新的修改记录。

## ⚠️ 常见问题

### Q: 点击浮动按钮没有反应？
**A:** 请检查：
1. **是否拖动了按钮？** 如果鼠标按下后移动超过5像素再释放，会被判定为"拖动"而不是"点击"
2. 确保快速点击，不要移动鼠标
3. 查看浏览器控制台日志，确认是否检测到点击事件
4. 刷新页面后重试

### Q: 无法关闭编辑器？
**A:** 请确认：
1. 直接点击蓝色浮动按钮（不要拖动）
2. 确保鼠标按下和释放的位置基本相同（移动距离小于5像素）
3. 或者使用快捷键 `Ctrl+Shift+E` / `Cmd+Shift+E`
4. 或者修改URL参数为 `?editor=false`

### Q: 按钮位置变了，但编辑器没切换？
**A:** 这是正常现象：
- 如果您按住按钮移动了位置，这属于"拖动"操作
- 只有快速点击（不移动或移动小于5像素）才会切换编辑器
- 拖动只是改变按钮位置，不会切换编辑器状态

### Q: 点击元素没有被选中？
**A:** 请确认：
1. 编辑器是否已启用（浮动按钮是蓝色）
2. 是否点击了编辑器面板（面板内的元素不会被选中）
3. 浏览器控制台是否有错误

### Q: 修改后页面没有刷新？
**A:** 请检查：
1. 是否点击了右侧面板的"保存"按钮？
2. 保存对话框是否确认了？
3. 浏览器是否阻止了自动刷新？

### Q: 修改了错误的元素？
**A:** 请注意：
- 每个元素都有唯一ID（data-editor-id属性）
- 使用右侧面板的修改记录查看修改了哪些元素
- 点击"清除"按钮可以撤销未保存的修改

## 📝 技术说明

### 唯一ID系统
每个被编辑的元素会自动获得唯一ID：
```html
<div data-editor-id="e-abc123" className="card">内容</div>
```

这确保修改只影响选中的元素，不会影响其他元素。

### 修改记录
所有修改都会记录：
- 修改类型（样式、内容、属性）
- 修改前后的值
- 元素选择器（基于唯一ID）

### 代码持久化
修改会直接写入源代码文件：
- 使用Babel AST解析和修改代码
- 保存后自动刷新页面
- 无需手动修改代码
