# 报告关联配置 - 层级联动选择器

## 概述

为了解决指标树页面数量众多的问题（可能有几十上百个页面），我们重新设计了页面选择器，采用**层级联动选择**的方式，按照"场景 → 指标树"的层级结构进行组织，大大提升了用户体验。

## 背景

### 问题分析

用户反馈：
- 离网维系下的当月全量客户离网客户数、当月拍照中高端客户离网客户数、当月拍照全球通客户离网客户数，这就是三颗指标树，也就是三个指标树页面。
- 中高端客户运营下的拍照中高端客户规模保有率、拍照中高端客户价值保有率、中高端一降到底占比也是三棵指标树，也是三个指标树页面。
- 如果直接平铺列表，可能会有几十上百个页面，用户体验非常差。

### 解决方案

采用**层级联动选择**：
- 第一级：场景选择（离网维系、中高端客户运营等）
- 第二级：页面列表（该场景下的概览页和指标树页）

## 核心特性

### 1. 自动关联（推荐）⭐

- **工作原理**：根据模板的"业务场景"自动关联到该场景下的概览页和所有指标树页
- **使用方式**：勾选"自动关联到相关页面"复选框
- **优势**：
  - 无需手动选择页面
  - 智能匹配，减少配置错误
  - 支持批量关联

**示例**：
- 选择业务场景："离网维系"
- 自动关联到（3个页面）：
  - ✓ 离网维系概览页
  - ✓ 当月全量客户离网客户数
  - ✓ 当月拍照中高端客户离网客户数
  - ✓ 当月拍照全球通客户离网客户数

### 2. 层级联动选择（手动）

- **工作原理**：按照场景 → 页面的层级结构进行选择
- **使用方式**：
  1. 展开场景分组（如"离网维系"）
  2. 查看该场景下的所有页面（概览页 + 指标树页）
  3. 勾选或取消勾选页面
  4. 支持场景级"全选/取消全选"
- **优势**：
  - 清晰的层级结构，一目了然
  - 支持批量操作（场景级全选）
  - 每个指标树都是独立的，可单独关联
  - 支持搜索页面名称

## 使用流程

### 创建模板时配置

1. **填写基本信息**
   - 模板名称
   - 报告类型
   - 报告层级
   - 业务场景（重要！）
   - 模板描述

2. **配置报告展示位置**
   - ✅ **推荐**：勾选"自动关联到相关页面"
   - 📝 **可选**：手动调整关联页面
     - 展开场景分组
     - 勾选/取消勾选页面
     - 支持场景级全选/取消全选
   - 👀 **查看**：已关联页面列表

3. **完成**
   - 点击"下一步"进入模板编辑

  static getScenarioConfig(scenarioId: string): ScenarioConfig | undefined

## 常见问题

### Q1：为什么每个指标树都是一个独立页面？

**A**：因为每个指标树都有独立的配置和数据，需要独立展示和分析。

### Q2：如何快速选中某个场景下的所有页面？

**A**：
1. 展开该场景
2. 点击场景头部的"全选"按钮

### Q3：如何查找某个特定的指标树页面？

**A**：
1. 在搜索框输入页面名称
2. 系统会自动筛选匹配的页面

### Q4：自动关联和手动选择可以同时使用吗？

**A**：可以！
- 先开启自动关联，系统会自动添加相关页面
- 然后使用手动选择展开场景，添加或删除其他页面
- 最终关联页面 = 自动关联页面 ∪ 手动选择页面

### Q5：如果我只想关联某个场景下的特定指标树，怎么办？

**A**：
1. 不开启自动关联，或开启后手动取消不需要的页面
2. 展开对应的场景
3. 只勾选需要的指标树页面
