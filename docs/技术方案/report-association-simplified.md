# 报告展示位置配置 - 简化版方案

## 概述

报告展示位置配置已经简化，采用"自动关联 + 手动选择"的方式，大大提升了用户体验。

## 核心特性

### 1. 自动关联（推荐）⭐

- **工作原理**：根据模板的"业务场景"自动关联到对应的概览页和指标树页
- **使用方式**：勾选"自动关联到相关页面"复选框
- **优势**：
  - 无需手动选择页面
  - 智能匹配，减少配置错误
  - 支持批量关联

**示例**：
- 选择业务场景："公众市场 / 客户运营 / 离网维系"
- 自动关联到：
  - ✓ 离网维系概览页
  - ✓ 离网维系指标树页

### 2. 手动选择

- **工作原理**：从页面列表中手动选择要关联的页面
- **使用方式**：
  1. 在"手动添加页面"区域搜索或浏览页面
  2. 点击页面即可添加或移除关联
- **优势**：
  - 灵活性高，可自定义关联
  - 支持搜索和筛选
  - 所见即所得

## 使用流程

### 创建模板时配置

1. **填写基本信息**
   - 模板名称
   - 报告类型
   - 报告层级
   - 业务场景（重要！）
   - 模板描述

2. **配置报告展示位置**
   - ✅ **推荐**：勾选"自动关联到相关页面"
   - 📝 **可选**：手动添加其他页面
   - 👀 **查看**：已关联页面列表

3. **完成**
   - 点击"下一步"进入模板编辑

### 创建报告时查看

1. **选择模板**
2. **查看报告展示位置**
   - 显示模板配置的默认关联位置（绿色高亮）
   - 可选择覆盖默认配置

## 自动关联规则

系统根据业务场景关键词自动匹配页面：

| 业务场景关键词 | 自动关联页面 |
|--------------|------------|
| 离网、churn | 离网维系概览页、离网维系指标树页 |
| 中高端、midhighend | 中高端客户运营概览页 |
| 市场、market | 市场运营概览页、市场运营指标树页 |
| 客户、customer | 客户运营概览页 |

## 常见问题

### Q1：为什么业务场景在基本信息中选了，展示位置还要再选？

**A**：新方案已经解决了这个问题！
- 旧方案：需要重复选择业务场景
- 新方案：根据基本信息中的业务场景自动关联，无需重复选择

### Q2：标签匹配怎么使用？

**A**：新方案已移除标签匹配
- 旧方案：标签匹配逻辑复杂，用户难理解
- 新方案：使用自动关联 + 手动选择，更加直观

### Q3：模块匹配怎么使用？

**A**：新方案已移除模块匹配
- 旧方案：模块匹配概念抽象
- 新方案：直接选择页面，所见即所得

### Q4：如果我想要更精确的控制怎么办？

**A**：使用手动选择功能
- 在"手动添加页面"区域，可以精确选择要关联的页面
- 支持搜索、筛选，快速找到目标页面

### Q5：自动关联和手动选择可以同时使用吗？

**A**：可以！
- 先开启自动关联，系统会自动添加相关页面
- 然后使用手动选择添加或删除其他页面
- 最终关联页面 = 自动关联页面 ∪ 手动选择页面

## 技术实现

### 组件结构

```
SimpleReportAssociationSelector
├── 自动关联开关
│   ├── Checkbox
│   ├── 业务场景显示
│   └── 自动关联页面预览
├── 手动添加页面
│   ├── 搜索框
│   └── 页面列表（可多选）
└── 已关联页面
    ├── 页面列表
    └── 删除按钮
```

### 数据流程

```
用户选择业务场景
    ↓
开启自动关联
    ↓
系统匹配自动关联页面
    ↓
用户可手动添加/删除页面
    ↓
最终关联页面列表
    ↓
保存到模板关联配置
```

### API接口

- **保存模板关联配置**：`POST /api/templates/[id]/associations`
- **获取模板关联配置**：`GET /api/templates/[id]/associations`
- **查询页面关联报告**：`GET /api/associations/pages/[pageId]/reports`
