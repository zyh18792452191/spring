# 效果跟踪模块设计文档

## 📋 需求概述

### 客户需求
在top5、bottom5基础上，要体现每个指标关联的活动情况：
- 针对该指标做了多少活动
- 总共有多少业务订购量
- 每个活动有多少业务订购量

### 全国视图
- 显示全国Top5和Bottom5指标
- 每个指标显示活动概览（活动数、总订购量）
- 点击指标可展开查看详细活动列表

### 分省视图
- 查看分省的指标改善情况
- 显示分省针对某指标做了多少活动
- 总共有多少业务订购量
- 每个活动有多少业务订购量

### 数据结构

#### 指标数据（Indicator）
```typescript
interface Indicator {
  id: string;              // 指标ID
  name: string;            // 指标名称
  code: string;            // 指标代码
  currentValue: number;    // 当前值
  targetValue: number;     // 目标值
  change: number;          // 变化百分比
  changeType: 'up' | 'down'; // 变化类型
  rank: number;            // 排名
  previousRank?: number;   // 上期排名

  // 活动数据
  activityCount: number;   // 活动总数
  totalOrders: number;     // 总业务订购量
  activities: Activity[];  // 活动列表
}
```

#### 活动数据（Activity）
```typescript
interface Activity {
  id: string;              // 活动ID
  name: string;            // 活动名称
  orderCount: number;      // 业务订购量
  date: string;            // 日期
  status: string;          // 状态（进行中/已完成/计划中）
  description?: string;    // 描述
}
```

#### 省份数据（ProvinceData）
```typescript
interface ProvinceData {
  provinceCode: string;           // 省份代码
  provinceName: string;           // 省份名称

  // 省份概况
  improvedCount: number;          // 改善的指标数
  totalIndicatorCount: number;    // 总指标数
  activityCount: number;          // 活动总数
  totalOrders: number;            // 总订购量
  averageImprovementRate: number; // 平均改善率

  // 该省的指标列表
  indicators: ProvinceIndicator[];
}
```

## 🔄 交互流程

### 全国视图交互

1. **查看指标列表**
   - 页面默认显示全国Top5和Bottom5指标
   - 每个指标显示基本信息和活动概览

2. **展开活动详情**
   - 点击指标卡片
   - 卡片展开，显示该指标的所有活动
   - 再次点击可收起

3. **查看全国概况**
   - 底部显示全国整体数据
   - 包括总指标数、改善指标数、总活动数、总订购量

### 分省视图交互

1. **选择省份**
   - 点击省份下拉框
   - 选择目标省份
   - 页面自动刷新显示该省数据

2. **查看省份概况**
   - 显示该省的整体数据
   - 包括改善指标数、活动总数、总订购量、平均改善率

3. **查看指标详情**
   - 显示该省的所有指标
   - 点击指标可展开查看活动详情

## 📊 数据展示策略

### 指标排序
- Top5：改善幅度最大的前5个指标
- Bottom5：改善幅度最小的5个指标（或恶化最严重的5个指标）

### 排名变化
- 显示排名上升/下降箭头
- 显示具体变化数值
- 例如：↑2 表示排名上升2位

### 活动状态
- **进行中**：蓝色标签
- **已完成**：灰色标签
- **计划中**：无填充边框标签

### 数值格式
- 订购量：转换为"万单"显示
- 百分比：保留1位小数
- 排名：整数

## 🎯 视觉设计

### 颜色方案

#### Top5（改善指标）
- 排名标签：绿色背景（`bg-green-100 text-green-700`）
- 变化箭头：绿色（`text-green-600`）
- 图标：绿色向上箭头

#### Bottom5（需改善指标）
- 排名标签：红色背景（`bg-red-100 text-red-700`）
- 变化箭头：红色（`text-red-600`）
- 图标：红色向下箭头

### 间距与布局
- 卡片间距：`gap-3`（12px）
- 卡片内边距：`p-4`（16px）
- 两栏布局：`grid-cols-2`
- 响应式：小屏幕改为单列

### 交互反馈
- 悬停效果：`hover:bg-gray-50`
- 阴影效果：`hover:shadow-md`
- 过渡动画：`transition-colors` / `transition-shadow`

## 📝 使用说明

### 访问页面
```
http://9.129.66.5:5000/portal/effect-tracking
```

### 基本操作
1. **查看全国数据**：默认显示全国视图
