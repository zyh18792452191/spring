# AI洞察助手录屏讲解词

## 一、准备工作

关掉所有软件，只留浏览器和录屏软件，打开系统页面用区公司/分公司（地州公司）运营人员角色登录。

## 二、开始录屏

大家好：

现在从能力中心的角度介绍一下新疆市场运营平台AI洞察助手的相关操作，完整演示"需求问答、数据准备、框架模板化配置、大模型自动生成、根因转工单派发"的端到端过程。

AI洞察助手是平台"AI+运营"体系的核心入口，基于大模型对经营数据自动开展异常识别、根因归因、客群关联与策略建议分析，并以自然语言的方式输出分析报告、数据报表、数据看板与数据摘要，将分析师从重复取数、写报告的繁琐工作中解放出来。

AI洞察助手承接集团洞察分析类验收要求，核心解决四个问题：

1. 支持模板化配置报告框架：报告框架可配置化，包含根因、客群、业务建议等核心模块；
2. 大模型驱动自动生成：自动生成、智能归因与自然语言输出；
3. 报告内容结构完整：包含异常描述、根因分析、关联客群特征、策略建议；
4. 根因可闭环处置：根因结论支持一键转为策略工单，联动调度中心派发。

AI洞察助手包含智能问答与数据准备、报告框架模板化配置、AI报告生成与智能归因、根因转工单联动派发、报告追问深化与归档沉淀等环节，下面逐一介绍。

## 第一部分：能力中心·洞察中心（AI洞察助手）

### 1、洞察中心入口与智能问答

点击顶部"能力中心"，进入"洞察中心"下的"AI洞察助手"，页面为全屏三栏布局：左侧为历史对话列表（可折叠），中间为对话区，右侧为数据与预览面板。

进入后对话区展示4个快捷入口卡片：洞察报告、数据报表、数据看板、数据摘要。本次演示选择"洞察报告"。

在输入框描述分析需求，例如："分析乌鲁木齐6月ARPU下降原因"。发送后，AI自动理解需求并按"需求收集→数据准备→大纲确认→产出物生成→追问深化"的流程自主推进，无需人工逐环节点选，体现大模型驱动的全流程自动化。

注释：页面定位在AI洞察助手对话区，演示快捷入口与需求输入，待介绍结束后进入数据准备环节。

### 2、数据准备

需求理解完成后，系统自动进入数据准备阶段，右侧面板自动展开。

数据源分为指标、指标树、客群、数据集、报表五类，同一时刻只能选择一类（类别互斥），类别内支持多选，确保分析口径一致。点击"选择指标"，弹出指标选择弹窗，支持按关键字搜索、按业务场景（流量运营、中高端客户运营、离网维系、家庭融合运营、国际业务运营、增量运营）筛选，分页加载；点击"选择客群"，可选择需重点关联分析的目标客群，为后续"关联客群特征"章节提供分析对象。

确认已选数据源后，右侧面板展示数据概要（数量、类别、覆盖范围），点击"确认数据"，进入下一环节。

注释：页面定位在数据准备面板，演示指标与客群数据源选择，待介绍结束后进入报告框架配置环节。

### 3、报告框架模板化配置

洞察报告支持模板化配置报告框架。系统提供三种取模板方式：从已归档报告选择、从模板库选择、上传报告模板（Word/PDF）。

点击"从模板库选择"，弹窗展示平台沉淀的各类报告模板，如"月度经营分析报告""收入波动归因报告""流量运营专项分析""中高端客户保有报告"等，每个模板展示名称、分类、章节数、更新时间，支持搜索与分类筛选。以"收入波动归因报告"为例，其模板框架已预置"收入概览、波动归因、收入结构、提升策略"等核心章节；选择后系统按模板框架自动生成报告大纲，大纲中明确包含根因分析、关联客群、策略建议（业务建议）等核心模块，章节结构可调整、可确认。

同时支持上传本地 Word/PDF 报告作为模板，系统自动提取章节结构并生成报告框架，实现"集团/省侧标准报告模板"的快速复用。

注释：页面定位在大纲确认弹窗，演示模板库选择与大纲框架，待介绍结束后进入报告生成环节。

### 4、AI报告生成与智能归因

确认大纲后进入产出物生成阶段，AI基于已选数据源自动生成报告内容，逐字流式输出。

报告正文结构完整覆盖集团要求四大模块：异常描述——AI先识别指标异常，例如提示"ARPU环比-3.2%触发异常"；根因分析——AI执行五层归因体系（分解归因、对比归因、区域归因、客群归因、因果推断）逐层下钻，输出"5G基础套餐推广策略→低价值用户占比上升→ARPU下降（置信度：高）"等因果结论；关联客群特征——自动关联受影响客群并刻画其特征（如"5G基础套餐新入网用户占新增62%，ARPU仅28-35元"）；策略建议——基于归因结论推演可执行建议（定价调整、专项攻坚、迁转目标等）。

生成完成后，洞察报告支持按Word/PDF格式导出，供内部传阅与汇报使用；数据报表、数据看板、数据摘要等其他生成类型则分别按表格、在线看板链接、文本摘要形式输出，满足不同场景需要。

注释：页面定位在报告生成预览区，演示流式生成与章节内容，待介绍结束后进入根因转工单环节。

### 5、根因转策略工单，联动调度中心派发

针对报告中的根因结论，平台支持一键转为策略工单，形成"洞察→处置"闭环。

演示时，基于报告根因分析得出的结论（如"乌鲁木齐、喀什ARPU降幅最大，主因低价值套餐用户占比上升"），将该根因一键生成策略工单，系统自动联动调度中心完成派发，后续由对应责任区域/责任人承接处置任务，处置进度可全程跟踪。

注释：页面定位在根因转工单联动画面（可衔接"能力中心-调度中心-调度总览"展示派发结果），待介绍结束后进入追问深化与归档环节。

### 6、追问深化与归档沉淀

报告生成后进入追问深化阶段，可继续与AI对话追问，例如"乌鲁木齐哪个区县降幅最大""针对中高端客群给出细分建议"，AI结合上下文继续输出。

该阶段支持"保存为模板"：将当前报告的章节结构一键沉淀到模板库，下次同类分析可直接复用，持续积累企业分析资产。确认完成后点击"归档"，报告归档至报告中心统一管理，本段对话即告完成。

注释：页面定位在追问深化与归档操作，待介绍结束后进入收尾总结。

## 三、收尾总结

以上是能力中心AI洞察助手场景的相关操作介绍。

AI洞察助手通过"模板化框架"实现报告结构的标准化配置与复用，通过"大模型自动生成"实现异常识别、五层归因与自然语言输出，通过"异常描述、根因分析、关联客群特征、策略建议"的完整报告结构，让每一份洞察报告既看得懂、又找得到原因、更落得了行动。

对照集团验收要求：报告框架支持模板化配置，包含根因、客群、业务建议等核心模块；大模型驱动自动生成，智能归因并以自然语言输出；报告完整包含异常描述、根因分析、关联客群特征、策略建议；根因结论支持一键转为策略工单、联动调度中心派发——四项要求全部落地。

AI洞察助手实现了从"数据看板"到"决策建议"、从"人工分析"到"AI洞察"的升级，让分析结论可归因、可解释、可执行，支撑市场运营向智能化、自动化方向持续演进。
