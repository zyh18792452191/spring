# 知识中心录屏讲解词

## 一、准备工作

关掉所有软件，只留浏览器和录屏软件，打开系统页面用区公司/分公司（地州公司）运营人员角色登录。

## 二、开始录屏

大家好：

现在从能力中心的角度介绍一下新疆市场运营平台知识中心场景的相关操作，完整演示知识库的创建、审核、发布、查询与使用的全过程。

知识中心是平台运营经验的沉淀与复用中心，将策略案例、营销话术、操作手册、场景知识四类核心知识统一管理，实现"优秀经验可沉淀、标准话术可复用、操作规范可传承"，为AI辅助定策提供知识供给，为一线运营人员提供即时知识支撑。

知识中心包含知识库管理和审核管理两大功能，下面逐一介绍。

---

## 第一部分：能力中心·知识中心

### 1、知识中心总览

点击顶部菜单"能力中心"，在"知识中心"下点击"知识库管理"，进入知识中心管理页。

知识中心承接集团知识库管理要求，核心解决三个问题：

1. 知识信息是否完整：覆盖策略案例（成功/失败）、营销话术、操作手册、场景知识四类内容，核心场景知识无缺失；
2. 知识内容可管理：支持按关键词搜索知识库信息，具备知识库信息的增删改查、审核、发布等完整管理能力；
3. 知识与场景强关联：每条知识关联具体业务场景（如携转挽留、全球通离网、停机赢回等），一线人员按场景即可找到对应知识。

知识中心包含知识库管理（知识的检索、新建、编辑、查看、删除）和审核管理（知识的提交、审核、发布、驳回）两大功能，下面逐一介绍。

注释：页面定位在能力中心-知识中心-知识库管理页，待介绍结束后进入知识库管理功能讲解。

### 2、知识库管理

点击"知识中心-知识库管理"，进入知识库列表页。

知识库管理页提供知识全量检索与管理能力。页面顶部为搜索筛选区：

- 关键词搜索：支持输入关键词对知识标题、摘要进行模糊搜索，并记录搜索历史，方便快速复用；
- 内容类型筛选：支持按策略案例、营销话术、操作手册、场景知识四类内容类型过滤；
- 关联场景筛选：支持按携转挽留、携出授权码、宽带存量关怀、全球通离网、全球通投诉、热线商机、异动修复、离网原因追溯、停机赢回等9大业务场景过滤；
- 状态筛选：支持按草稿、待审核、已发布、已驳回、已下线五种状态过滤。

页面右上角展示知识总条数，支持"新建知识"入口，并提供列表/卡片两种视图切换：列表视图展示知识标题、内容类型、关联场景、状态、创建人、更新时间、操作列，适合批量管理；卡片视图以卡片形式展示标题、状态、类型、摘要、标签、浏览数，适合快速浏览。

列表中的每条知识支持按状态差异化的操作：草稿、已驳回、已下线状态支持编辑与删除；草稿、已驳回状态支持提交审核；所有状态均可点击标题或"查看"按钮进入详情页。

注释：页面定位在知识库管理列表页，演示搜索、筛选、视图切换，待介绍结束后进入新建知识功能。

### 3、新建知识

点击"新建知识"按钮，进入知识创建页。

新建知识页由三大部分组成：基本信息、正文内容、附件。

**基本信息区**：

1. 知识标题：必填，限50字，需清晰概括知识核心内容；
2. 内容类型：必填，支持策略案例、营销话术、操作手册、场景知识四选一；
3. 关联场景：必填，支持多选，将知识挂接到一个或多个业务场景（携转挽留、全球通离网、停机赢回等9大场景），确保知识可按场景检索；
4. 案例结果：仅当内容类型为"策略案例"时展示，标注案例为"成功"或"失败"，沉淀经验与教训；
5. 知识标签：支持从预置标签（最佳实践、高频问题、新手必读、失败教训、话术模板、流程规范）中选择，也支持输入自定义标签，便于多维分类检索；
6. 摘要：必填，限200字，用于列表展示和搜索结果预览。

**正文内容区**：提供富文本编辑能力，支持加粗、斜体、无序列表、表格、插入图片、代码块等格式，满足策略案例、操作手册等结构化知识撰写需求。

**附件区**：支持上传PDF、Word、图片格式附件，单文件限10MB，可作为正文的补充材料。

页面右上角提供"保存草稿"和"提交审核"两个操作：保存草稿将知识保存为草稿状态，可后续继续编辑；提交审核会校验标题、内容类型、关联场景、摘要、正文等必填项，校验通过后知识进入待审核状态。

注释：页面定位在新建知识页，演示表单填写与提交，待介绍结束后进入知识详情功能。

### 4、知识详情

点击知识列表中的某条知识标题，进入知识详情页。

知识详情页完整展示知识内容：标题、内容类型（策略案例/营销话术/操作手册/场景知识）、关联场景、案例结果（策略案例特有）、知识标签、摘要、正文内容、状态、创建人、创建时间、更新时间、浏览数等信息。

以一条已发布的"携转挽留策略案例"为例，正文包含五大章节：背景（问题现状与数据）、策略设计（关键信号识别）、执行方案（差异化挽留方案表）、执行效果（核心指标变化）、经验总结（可复用的方法论），完整呈现了一个优秀案例从发现问题到沉淀经验的全部过程，供其他地市直接参考复用。

处于草稿、已驳回、已下线状态的知识，详情页支持点击"编辑"按钮返回编辑页继续修改。

注释：页面定位在知识详情页，演示案例知识全文展示，待介绍结束后进入审核管理功能。

### 5、审核管理

点击"知识中心-审核管理"，进入知识审核页。

审核管理页采用Tab页签组织，包含"待审核"、"已通过"、"已驳回"等页签，实现知识发布的全流程管控。

**待审核页签**：展示所有提交待审的知识条目，包含知识标题、内容类型、关联场景、提交人、提交时间、摘要、正文、标签等信息。审核人可点击"通过"或"驳回"按钮进行审核，驳回时需填写审核意见，说明驳回原因，便于提交人针对性修改后重新提交。

**已通过页签**：展示审核通过的知识条目，记录审核人、审核时间、审核意见，通过后知识即进入已发布状态，全员可见可查。

**已驳回页签**：展示被驳回的知识条目及驳回意见，提交人可据意见修改后重新提交审核。

审核流程形成"创建→提交→审核→发布→使用"的完整闭环，确保知识质量可控、发布合规、内容可信。

注释：页面定位在审核管理页，演示待审核列表与审核操作，待介绍结束后进入收尾总结。

## 三、收尾总结

以上是知识中心场景的相关操作介绍。

知识中心通过"知识库管理"实现策略案例（成功/失败）、营销话术、操作手册、场景知识四类知识的统一沉淀与检索，通过"审核管理"实现知识的提交、审核、发布全流程管控，将一线优秀运营经验转化为可复用、可传承的平台资产，为AI辅助定策提供高质量的知识供给，为省、地市、网格各级运营人员提供即时、精准、权威的知识支撑。

平台通过知识中心的建设，实现了"经验数据化、数据资产化、资产服务化"的运营知识闭环，支撑市场运营平台持续进化。
