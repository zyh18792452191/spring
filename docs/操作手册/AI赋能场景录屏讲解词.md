# AI赋能场景录屏讲解词

## 一、准备工作

录制前请确认以下内容：

1. **录制环境**：关闭所有无关软件，仅保留浏览器与录屏软件；使用分公司/地市运营人员账号登录平台。
2. **演示数据准备**：
   - 洞察中心已存在覆盖流量、存量、细分市场场景的指标树（系统预置即可），并有一个可展示预警状态的指标树节点；
   - 预警规则配置中已有至少一条生效规则（如"离网客户数环比增长预警"），便于演示预警清单；
   - AI洞察助手可直接使用系统预置报告模板（如月度经营分析模板）；
   - 流量运营页面准备一个带预警标识的核心指标卡片（如"流量增幅"），用于演示"去调度"。
3. **录制路径提示**：本解说词共三个部分，建议按顺序录制；AI智能调度为本次演示重点，人员匹配Agent的流式分析过程请勿加速、完整录制。

## 二、开场白

大家好：

下面从集团"运营注智"方向，介绍新疆移动市场运营平台在 **AI赋能场景** 下的三类核心能力——**AI指标监控预警**、**AI数据洞察报告**与**AI智能调度**。

平台围绕"让AI看懂指标、写好报告、派准工单"构建了完整的注智体系：

- **AI指标监控预警**：核心场景指标全覆盖、7×24小时自动盯盘，异动即预警，规则可配置、消息直达责任人，异常可下钻定位；
- **AI数据洞察报告**：模板化框架与大模型结合，把指标异动自动"翻译"成看得懂、能落地的分析报告，根因结论还能一键转成策略工单；
- **AI智能调度**：工单自动排序，按"责任田+人员技能标签"匹配最合适的执行人，让每条工单都派得准、干得快。

下面分三个部分逐一演示。

## 第一部分：AI指标监控预警

### 1、核心场景指标全域监控

【演示动作】点击顶部菜单"能力中心"，下拉选择"洞察中心→洞察总览"进入。

平台在洞察总览页对全疆核心场景指标进行集中监控。页面按**指标树**组织，覆盖了流量运营、离网维系、中高端保有、家庭融合、国际漫游等流量、存量、细分市场核心场景指标，关键指标无缺失，实现了"一张图看全疆"。

我们打开流量运营相关的指标树，逐层展开可以看到该场景下的核心指标状态：指标正常时以绿色健康值展示；指标出现异动时，节点会直接带出**预警标识**和预警文案。例如这条预警展示的是"本月离网客户数较上月增长15%，超过预警阈值"——系统不仅提示"有问题"，还把异动量化为"较上月增长15%"，运营人员一眼就能抓住异常方向。

注释：页面定位在洞察中心→洞察总览，演示指标树视图、逐层展开、预警标识与预警文案。

### 2、预警规则灵活配置

【演示动作】点击该指标的预警规则入口，打开预警规则配置抽屉。

监控不是"一刀切"，平台把预警规则的配置权交给业务侧。这里可以看到当前指标已配置的规则与对应的预警等级，规则覆盖了多种触发口径：

- **按指标值（阈值）**：如"5G渗透率低于45%即触发预警"；
- **按同比口径**：如"离网客户数较去年同期增长即预警"；
- **按环比口径**：如"离网客户数环比上月增长即预警"；
- **按目标差距**：如"新增客户数低于目标值即预警"。

预警等级分为红、橙、黄、蓝四级，不同等级对应不同的关注程度与处置节奏。

我们现场新建一条规则演示配置过程：选择需要监控的指标，选定**计算口径**（按指标值计算、按同比计算或按环比计算），填写触发**阈值**，选择**预警等级**，保存后规则立即生效；对已配置的规则，支持随时**编辑修改**，也支持一键**停用/启用**，真正做到规则灵活可配、随业务策略调整。

注释：演示预警规则抽屉的查看、新建（选指标→选口径→填阈值→选等级→保存）、编辑与启停操作。

### 3、预警触达相关负责人

【演示动作】切换至顶部菜单"我的工作台"，从左侧导航进入"洞察管理→预警管理→预警配置管理"。

预警信息要"看得见、发得对、到得了人"。预警配置管理页集中管理平台所有预警规则，展示规则的预警名称、业务类型、客户类型、更新周期、**执行渠道**、归属区域与审批状态。

每条规则在配置时都会指定**执行渠道**与执行对象，可选渠道包括网格经理、地市集运、10088、10086、政企客户经理等。也就是说，一条预警触发后，系统会按配置的渠道把预警信息推送给对应区域的执行人，实现预警到人、任务到岗。

为了保证"预警找得到真正负责的人"，平台在"洞察管理→指标管理→**指标看管人**"中为每个核心指标绑定了看管负责人（含部门、联系方式），预警触达的对象正是这些对指标结果负责的看管人，从机制上避免"预警发了、没人接、责任落不实"。

注释：依次切到预警配置管理页（讲执行渠道、启停状态、审批流）与指标看管人页（讲指标-负责人绑定关系）。

### 4、预警清单回溯与指标下钻定位异常

【演示动作】从左侧导航进入"预警管理→预警清单"。

预警清单沉淀了系统全部已触发的预警记录，按**指标预警**与**商机预警**分页展示，每条记录包含预警指标/分类、预警等级、预警内容、预警时间与处理状态，支持按等级、状态、时间筛选与关键词搜索，运营人员可随时回溯"什么时间、哪个指标、发了什么预警、处理到什么程度"。

发现预警只是第一步，定位异常才是关键。

【演示动作】回到洞察总览，点击预警指标进入指标详情。

对触发预警的指标，点击即可进入指标详情页，按**省—市—县—格**逐级下钻，也可以按**客群、产品**维度拆分。例如：全疆离网指标预警后，下钻到乌鲁木齐，再逐层到区县、网格，最终锁定到底是哪个网格、哪类客群贡献了主要异常，为制定处置策略提供精确靶点，实现"预警可下钻、异常可定位"。

注释：演示预警清单的列表与筛选，再从预警指标进入详情，完成省—市—县—格逐级下钻。

## 第二部分：AI数据洞察报告

### 1、AI洞察助手与模板化报告框架

【演示动作】点击顶部菜单"能力中心→洞察中心→AI洞察助手"进入。

平台把"写报告"这件事交给了大模型。AI洞察助手支持生成**洞察报告、数据报表、数据看板、数据摘要**四类产出物，其中洞察报告解决的是"指标为什么波动、背后是谁、下一步怎么办"的分析诉求。

报告不是随意生成的，而是基于**可配置的模板框架**。平台预置了多套报告模板（如月度经营分析、专项归因分析等），模板按"**核心指标概览→分解归因分析→区域对比分析→客群分析→策略建议**"组织章节——这套框架正好承载了报告必须具备的异常描述、根因分析、关联客群特征与业务建议四大核心模块；业务侧也可以把沉淀下来的优秀分析结构保存为自有模板，实现"框架可配、内容AI写"。

注释：页面定位在AI洞察助手，演示快捷入口卡片，点选"洞察报告"，口播模板框架章节结构。

### 2、大模型自动生成洞察报告

【演示动作】在对话框输入分析需求，例如"分析乌鲁木齐5G用户发展放缓的原因"，点击发送。

AI洞察助手自动推进全流程：

第一步**大纲生成**：AI理解需求后，先生成报告大纲，明确本次分析要覆盖的章节框架；
第二步**数据准备**：选择本次分析引用的数据源——平台指标、指标树、客群、数据集或报表均可，系统自动给出已选数据源与数据概要，确认后进入生成；
第三步**AI自动生成**：大模型按大纲自动撰写报告内容，以流式打字机方式逐段呈现。报告中既有核心指标的表现概览，也有**分解归因分析**——自动定位影响最大的细分项并解释原因；还包含**关联客群特征**——指出哪类客群在异动中贡献最大；最后给出基于根因的**策略建议**，全程自然语言输出。

业务人员不需要写SQL、不需要手工翻报表，直接在对话中获得一份逻辑完整、可直接阅读的分析结论。

如果生成方向不满意，可以在大纲阶段调整章节；生成后还可以继续**追问深化**，比如"再对比分析一下喀什的情况"，AI会在原报告基础上迭代补充，实现"对话即分析"。

注释：完整演示"输入需求→大纲→数据准备→AI生成"自动推进链路，突出大模型归因与自然语言输出，Agent流式渲染过程完整录制。

### 3、报告导出、模板沉淀与归档

【演示动作】生成完成后，演示导出与归档操作。

生成的洞察报告支持一键导出为 **Word/PDF**，方便线下汇报与存档；点击"保存为模板"可以把本次报告的章节结构沉淀到模板库，下次同类分析直接复用；确认无误后可将报告**归档**，沉淀至报告中心统一管理，逐步积累形成企业的分析资产库。

注释：演示导出格式选择、保存为模板、归档三步操作。

### 4、根因结论一键转策略工单

报告产出的根因结论不只是"看看"，更要落到"干"。

当报告定位到明确根因后，平台支持把根因结论**一键转为策略工单**：将根因对应的处置策略、目标客群自动带入调度流程，联动调度中心完成人员派发，形成"洞察→策略→调度→执行"的自动衔接，让分析结论直接驱动运营动作，而不是停留在文档里。

（策略工单中的人员智能匹配环节，将在第三部分AI智能调度中演示。）

注释：此处用话术衔接策略中心与调度中心，无需切屏深演示，避免与第三部分重复。

## 第三部分：AI智能调度（以流量运营场景为例）

### 1、场景入口：从流量运营发起指标调度

AI智能调度已接入**指标调度**与**策略调度**两类工单，覆盖流量运营、中高端运营、离网维系、家庭运营等场景，本部分以流量运营为例进行完整演示。

【演示动作】点击顶部菜单"市场运营→流量运营"，进入流量运营工作台。

页面展示流量增幅、流量份额、手机上网业务量等核心指标卡片。可以看到"流量增幅"卡片已带**橙色预警**——本月该指标出现异动，卡片同时展示了当月值与环比变化。点击卡片右上角"**去调度**"，发起一次指标调度任务。

注释：页面定位在市场运营→流量运营，演示带预警指标卡片的"去调度"入口。

### 2、选择区域、确认指标与目标

【演示动作】在弹出的指标调度窗口中完成步骤一"选择区域"。

调度窗口第一步为"选择区域"：系统自动带出该指标所辖的派发区域，可勾选需要下发的区域范围（全疆或相关地市）；随后确认本次的问题指标与期望目标值，点击"下一步"进入调度派发环节。

注释：演示勾选派发区域、确认问题指标与目标值，点击下一步。

### 3、人员匹配Agent智能匹配执行人员（核心演示）

【演示动作】进入第二步"调度派发"，放慢节奏完整录制。

进入调度派发环节后，页面顶部出现"**人员匹配Agent**"面板，系统自动为每个区域的派发任务匹配执行人员，并以流式日志实时呈现分析过程——"共N个任务"，逐一任务开始分析。

Agent的智能匹配逻辑分四步走：

**第一步，责任田定界**：每个任务先锁定责任田范围，只在该区域对应的网格人员中寻找执行人，确保"自己的田自己种"，从机制上保证责任归属清晰；
**第二步，池内打分**：对责任田内的候选人员，按"**技能标签匹配 + 历史执行效能**"两个维度进行综合打分，既看这个人会不会干，也看他以往干得怎么样；
**第三步，灰色地带裁决**：当候选人员得分差距过小、规则难以直接决断时，自动进入AI裁决环节，结合更多维度的信息给出最优人选；
**第四步，生成推荐**：为每个任务生成推荐执行人，并附带完整的匹配原因说明。

同时，Agent在分析前会按**商机价值、客户等级、执行时效**对任务自动排序——高价值、高时效的任务优先匹配、优先展示，确保资源向关键任务倾斜。

【演示动作】等Agent面板显示"分析完成"后，指向下方任务表格。

匹配结果自动回填到任务表格：每个任务展示了**推荐执行人**（姓名+部门）、**匹配方式**（如"责任田规则、技能标签"）、**综合分**与**匹配原因**；对责任田内无合适人员的任务，系统会给出降级处理建议（如升级至上级网格处理），保证每个任务都有明确的处理去向，没有漏派、不错派。

注释：核心演示区。跟随Agent面板流式日志逐行讲解"责任田→打分→裁决→推荐"四步，再指出表格回填的推荐执行人、匹配方式、综合分、匹配原因，以及无合适人选时的升级降级逻辑。

### 4、确认派发，闭环完成

【演示动作】核对任务表格内容，填写任务要求，选择审批人与派发系统，点击"派发"。

运营人员核对AI推荐的执行人结果：如果认可，可直接采用推荐执行人；如需调整，也可以手动更换接收人后重新匹配。随后填写**任务要求**、选择**审批人**与**派发系统**（市场运营平台本系统），点击"**派发**"，任务即生成调度工单。

派发完成后，工单进入调度中心与工作台统一跟踪，执行进度、子任务完成情况全程可查。

至此，"发现指标异动→AI自动匹配执行人→一键派发到人"的智能调度闭环演示完成。需要说明的是，策略调度同样接入了人员匹配Agent，执行流程与指标调度一致，此处不再重复演示。

注释：演示确认任务、填写任务要求、选择审批人与派发系统、点击派发；口播说明策略调度同流程，避免重复录制。
