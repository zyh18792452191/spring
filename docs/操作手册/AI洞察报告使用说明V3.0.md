# AI洞察报告使用说明

> 本文档面向市场数智运营平台的所有用户，按操作流程组织，帮助你快速掌握AI洞察助手的完整使用方法。

---

## 1. 快速入门

### 1.1 进入AI洞察助手

在平台顶部导航栏，点击 **能力中心 > 洞察中心 > AI洞察助手**，进入全屏对话界面。

### 1.2 五步生成第一份报告

1. **描述需求**：在输入框中输入你的分析需求，例如"分析乌鲁木齐6月ARPU下降原因"
2. **选择数据源**：点击数据按钮（平台指标/指标树/客群/数据集/报表），在弹窗中选择需要的数据，选择账期，点击"确认数据"
3. **确认大纲**（仅报告类型）：AI生成报告大纲，你可以在对话中调整，满意后点击"确认大纲"
4. **等待生成**：AI自动完成数据采集→数据校验→分析引擎→报告构建4步
5. **追问与归档**：阅读报告，继续追问补充分析，满意后点击"归档"

## 2. AI洞察助手详细操作

### 2.1 开始页

进入AI洞察助手后，会看到4个快捷入口卡片：

| 卡片 | 生成类型 | 适用场景 |
|------|---------|---------|
| 洞察报告 | report | 结构化多章节分析报告，如月度经营分析 |
| 数据报表 | spreadsheet | 行列数据表，如指标对比表 |
| 数据看板 | dashboard | KPI卡片+图表组合，如运营监控看板 |
| 数据摘要 | summary | 关键发现列表，如快速了解某指标异动 |

**点击卡片**：直接设定生成类型并开始对话。

**不点卡片**：直接在输入框输入需求，AI自动判断生成类型（默认为洞察报告）。

### 2.2 选择生成类型

4种生成类型的区别：

| | 洞察报告 | 数据报表 | 数据看板 | 数据摘要 |
|---|---------|---------|---------|---------|
| 产出形态 | 多章节结构化报告 | 行列数据表 | KPI卡+图表 | 关键发现列表 |
| 需要确认大纲 | ✅ 是 | ❌ 否 | ❌ 否 | ❌ 否 |
| 可导出格式 | Word/PDF | Excel/CSV | 在线链接/PDF截图 | 文本/PDF |
| 典型场景 | 月度经营分析 | 指标对比表 | 运营监控 | 快速了解异动 |

### 2.3 需求收集

在输入框中用自然语言描述你的分析需求。

**输入示例**：
- "生成本月经营分析报告"
- "分析乌鲁木齐6月ARPU下降原因"
- "对比16地市5G登网率"
- "帮我看看流量运营的关键发现"

**注意**：AI理解需求后会自动推进到数据准备阶段，无需手动点击"确认需求"。

### 2.4 数据准备

#### 2.4.1 选择数据源

点击输入框下方的数据按钮，打开对应弹窗：

| 按钮 | 数据源类别 | 说明 |
|------|-----------|------|
| 选择数据集 | dataset | 上传的原始数据文件 |
| 平台指标 | indicator | 平台内置指标体系 |
| 指标树 | tree | 指标树结构 |
| 选择客群 | group | 客群圈选结果 |
| 选择报表 | report | 平台业务报表 |

**重要：5类数据源互斥**。选择任一类别后，其他类别的选择项会灰显不可点击。如需换类别，先清空已选数据源（点击已选数据源列表底部的"清空全部"按钮）。

**每个弹窗均支持**：
- 搜索框：按名称搜索
- 业务场景筛选：流量运营/中高端客户运营/离网维系/家庭融合运营/国际业务运营/增量运营
- 分页：每页8条

#### 2.4.2 已选数据源管理

选择数据源后，右侧面板展示已选列表：
- **删除单项**：hover每条数据源卡片，右上角出现X按钮，点击移除
- **清空全部**：点击列表底部"清空全部"按钮，移除所有已选数据源并重置类别

#### 2.4.3 选择账期

右侧面板的账期选择器：

| 账期类型 | 选择控件 | 默认值 |
|---------|---------|--------|
| 日度 | 年+月+日 | 当天 |
| 月度 | 年+月 | 当月 |
| 季度 | 年+季度 | 当季 |
| 半年 | 年+上下半年 | 当前半年 |
| 年度 | 年 | 当年 |

**选择数据集时**：账期选择器自动隐藏（数据集自带时间信息，无需指定账期），数据概要中展示"数据集自带账期"。

#### 2.4.4 模板选择（仅洞察报告类型）

如选择洞察报告类型，AI会引导你选择模板。3种方式：

1. **从已归档报告选择**：从你之前归档的报告中提取结构
2. **从模板库选择**：浏览系统预设和自定义模板
3. **上传报告模板**：选择本地Word/PDF文件，系统提取章节结构

**跳过模板**：点击"跳过模板选择，直接开始"，不使用模板直接进入下一步。

**换模板**：在对话中说"换模板"或"重新选择模板"，系统重新展示模板选择。

#### 2.4.5 确认数据

确认数据源和账期后，点击右侧面板的"确认数据"按钮。

**确认后**：数据源按钮变为不可点击，无法再修改数据源。如需修改，需创建新对话。

### 2.5 大纲确认（仅洞察报告）

确认数据后，AI生成报告大纲，右侧面板展示章节结构树。

**操作方式**：
- 在对话中用自然语言调整大纲，例如"在风险预警下加一个ARPU异动分析""去掉竞品分析章节"
- 满意后点击"确认大纲"按钮

**非报告类型**（报表/看板/摘要）：跳过此步骤，确认数据后4秒自动推进到产出物生成。

### 2.6 产出物生成

AI自动执行4步流程，右侧面板实时展示进度：

1. **数据采集**：获取所需数据
2. **数据校验**：校验完整性和口径一致性
3. **分析引擎**：执行因果推理/归因分析/趋势预测
4. **报告构建**：生成各章节/整合报告结构

**此阶段无需操作**，等待4步全部完成即可。

### 2.7 追问深化

报告生成完毕后进入追问阶段。

**操作**：
- 继续追问：在输入框输入追问内容，AI基于报告上下文补充分析
- 归档：点击"归档"按钮
- 导出：点击"导出为▼"下拉菜单，选择格式下载
- 保存为模板（仅报告类型）：点击"保存为模板"，将当前章节结构保存到模板库

**追问示例**：
- "按地市拆分ARPU降幅"
- "5G登网率下降的主要原因是什么"
- "有哪些改善建议"

**换数据**：如果说"我要重新选择数据"，AI会提示你创建新对话重新选择。

### 2.8 归档

点击"归档"按钮后，弹出归档设置弹窗：

#### 可见性选择

| 选项 | 含义 | 谁能看到 |
|------|------|---------|
| 🔒 仅自己 | 默认，私有 | 只有你自己 |
| 📍 本区域 | 团队共享 | 你所属区域（地市/省公司）的所有人 |

- 省公司人员选"本区域"→全疆可见
- 地市人员选"本区域"→仅本地市可见

**归档后效果**：
- 输入框禁用，提示"已归档，点击重新打开继续编辑"
- 产出物出现在下载专区AI洞察Tab
- "仅自己"→"我的"Tab可见
- "本区域"→"团队"Tab可见

#### 已归档状态操作

| 按钮 | 功能 |
|------|------|
| 重新打开 | 恢复到追问深化阶段，可继续编辑 |
| 导出为▼ | 选择格式下载产出物 |
| 前往下载 | 跳转下载专区AI洞察Tab |

### 2.9 对话管理

#### 新建对话

点击左侧对话列表顶部的"新建对话"按钮，或点击汉堡图标展开侧栏后新建。

**新建后**：所有业务状态重置（消息/步骤/数据源/模板/账期/生成类型等），开始全新对话。

#### 切换对话

在左侧对话列表中点击其他对话，切换到对应对话。所有持久化状态（消息/步骤/数据源/模板等）自动恢复。

#### 搜索对话

在对话列表的搜索框中输入关键词，按对话标题搜索。

## 3. 数据源管理

### 3.1 进入数据源管理

左侧侧边栏：AI洞察管理 > 数据源管理

### 3.2 查看数据源列表

支持列表视图和卡片视图切换。

**筛选条件**：搜索框 + 数据格式筛选 + 质量状态筛选

### 3.3 上传数据

1. 点击"上传数据"按钮
2. 在弹窗中选择Excel或CSV文件
3. 系统自动解析字段信息
4. 预览前10行数据确认
5. 指定业务场景
6. 确认上传

**上传后**：数据源自动进入"待校验"质量状态，系统后台进行质量评估。

### 3.4 查看数据源详情

点击列表中的数据源名称，打开详情弹窗：

| Tab | 内容 |
|-----|------|
| 基本信息 | 名称/场景/格式/时间范围/数据量/质量评分 |
| 字段信息 | 字段名/类型/口径说明的表格 |
| 数据样本 | 前10行数据预览 |
| 引用记录 | 报告名称+状态（进行中/已归档） |

### 3.5 删除数据源

点击列表中的删除按钮。**注意**：已被报告引用的数据源不可删除。

## 4. 模板管理

### 4.1 进入模板管理

左侧侧边栏：AI洞察管理 > 模板管理

### 4.2 创建模板

3种创建方式（按推荐度排序）：

#### 方式1：AI对话创建（推荐）

1. 点击"AI创建"按钮（主色按钮）
2. 跳转到AI创建模板页面
3. 在左侧对话区描述报告结构需求
4. AI生成章节结构，展示在右侧编辑区
5. 在右侧编辑区调整章节（添加/删除子章节、添加段落）
6. 设置模板名称和标签
7. 保存到模板库

#### 方式2：从历史报告提取

1. 点击"从历史报告提取"按钮
2. 在历史报告列表中搜索和筛选
3. 点击要提取的报告
4. 系统提取章节结构
5. 编辑调整后保存

#### 方式3：手动创建

1. 点击"手动创建"文字链接
2. 跳转到模板编辑页面
3. 手动添加章节和段落
4. 设置模板名称和标签
5. 保存

### 4.3 编辑章节结构

章节支持**无限层级**递归嵌套：

- 每级章节可添加子章节
- 每级章节可添加段落（4种类型）
  - 文本段落：描述性文字
  - 数据表格：行列数据展示
  - 图表分析：趋势图/对比图/占比图
  - 分析说明：分析方法和结论
- 每级章节和段落可删除

### 4.4 模板标签

模板使用标签体系分类（非业务场景筛选）：

可用标签：经营分析、流量运营、客户分析、收入分析、5G发展、竞争分析、风险预警、渠道分析、宽带业务、月度报告、专项分析

### 4.5 模板来源标识

每个模板卡片展示来源标识：
- AI创建
- 手动创建
- 历史报告提取

顶部导航：能力中心 > 下载中心 > 下载专区

或从AI洞察助手已归档状态点击"前往下载"按钮。

### 5.2 查找文件

**4个Tab**：
- 全部：所有可查看的文件
- 报表：平台业务报表
- 数据洞察报告：数据洞察报告

**筛选条件**：

- 时间范围
- 范围：我生成的 / 团队 / 全部

### 5.3 AI洞察分析Tab特殊说明

此Tab展示AI洞察助手归档的产出物，包括：
- 你自己创建的所有产出物（含"仅自己"可见性的）

**可见性标识**：
- 🔒 仅自己：只有你能看到
- 📍 本区域：你所属区域的所有人都能看到

**生成类型标识**：
- 洞察报告（蓝色）
- 数据报表（绿色）

## 6. 常见问题

### Q1：数据源选错了怎么办？

在确认数据之前，可以在右侧面板的已选数据源列表中：
- 点击X按钮删除单项
- 点击"清空全部"重置

确认数据后无法修改，需新建对话重新选择。

### Q2：5类数据源为什么不能同时选？

5类数据源（数据集/指标/指标树/客群/报表）是互斥的，因为它们代表不同的分析维度，同时选择会导致数据口径不一致。选了一类后，其他类自动灰显。如需换类别，先清空已选。

### Q3：选了数据集为什么没有账期选择器？

数据集是用户上传的原始数据，时间信息已包含在数据本身中（如Excel中的"月份"列），不需要额外指定账期。平台指标/指标树/客群/报表则需要指定账期，因为它们的数据按账期存储在平台中。

### Q4：归档后还能修改报告吗？

可以。点击"重新打开"按钮，恢复到追问深化阶段，可继续追问和编辑。

### Q5：归档时选了"本区域"，其他人怎么看到？

其他人在下载专区切换到"团队"Tab或"全部"Tab，就能看到你设为"本区域"可见的产出物。

### Q6：非报告类型（报表/看板/摘要）没有大纲确认步骤吗？

没有。只有洞察报告需要确认大纲。报表/看板/摘要确认数据后自动生成，4秒后进入追问深化阶段。

### Q7：对话刷新页面后会丢失吗？

不会。对话自动持久化到浏览器本地存储，刷新后对话列表中可以恢复。但清除浏览器数据会丢失，建议及时归档重要报告。

### Q8：AI生成的报告数据准确吗？

AI生成的分析基于平台真实数据，但分析结论由AI推理得出。输入框下方有"内容由AI生成，仅供参考"的提示，重要决策建议人工核实关键数据。

### Q9：导出格式怎么选？

根据生成类型选择：
- 洞察报告→Word（方便编辑）或PDF（方便分享）
- 数据报表→Excel（方便二次分析）或CSV（方便导入其他系统）
- 数据看板→在线链接（实时更新）或PDF截图（静态快照）
- 数据摘要→文本（方便复制）或PDF（方便存档）

### Q10：模板里为什么不设置关联指标和数据来源？

模板是报告的**结构定义**（定义有哪些章节、每个章节分析什么主题），不涉及具体数据。指标和数据来源在AI洞察助手生成报告时选择和绑定，这样同一个模板可以用不同月份的数据反复生成报告。
