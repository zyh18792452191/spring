## 一、产品简介

AI洞察报告是市场数智运营平台的AI原生报告生成模块，帮助运营人员通过自然语言对话快速生成结构化的数据分析报告，并提供洞察知识库沉淀、模板复用、审核定稿等全流程能力。

### 核心特点

- **AI原生对话驱动**：通过自然语言描述需求，AI自动理解、规划、生成报告
- **六步骤状态机**：需求收集→数据准备→大纲确认→报告生成→追问深化→审核定稿，流程清晰可控
- **多数据源接入**：支持文件上传、平台数据集、指标体系、客群数据等多种数据来源
- **洞察知识库**：自动沉淀分析洞察，支持跨报告复用
- **模板体系**：保存成功报告结构为模板，一键复用
- **浮窗助手**：全局轻量级AI对话入口，支持页面上下文感知

### 页面清单

| 页面 | 路径 | 用途 |
|------|------|------|
| AI洞察首页 | `/workspace/ai-insight` | 报告生成主入口，含开始页、报告编辑页 |
| 洞察知识库 | `/workspace/ai-insight/knowledge` | 洞察条目管理与检索 |
| 报告中心 | `/workspace/ai-insight/reports` | 已有报告管理（草稿/待审核/已定稿/已废弃） |

## 二、使用场景速查

以下6个场景覆盖AI洞察报告的完整使用范围，每个场景回答一个独立的用户问题，场景之间无业务目的重叠：

| 序号 | 场景 | 回答的用户问题 | 适合谁 | 对应操作流程 |
|------|------|--------------|--------|------------|
| 1 | **月度经营分析报告**（最核心） | 定期报告怎么高效出？ | 市场部综合管理员 | 流程二（三条路径） |
| 2 | **指标异动分析** | 指标出问题了怎么分析？ | 业务线运营/区域运营 | 流程三（两种入口） |
| 3 | **从零创建专项分析报告** | 没有参考怎么从零创建？ | 新入职运营人员 | 流程一（从空白开始） |
| 4 | **审阅追问已有报告** | 已有报告怎么审阅修改？ | 部门经理 | 流程五+流程六 |
| 5 | **引用洞察生成专题报告** | 好洞察怎么深入变成报告？ | 业务主管 | 流程四（引用洞察） |
| 6 | **页面上下文感知分析** | 在运营页面怎么即时提问？ | 所有运营人员 | 流程八（浮窗感知） |

**跨场景功能特性**：洞察自动沉淀与复用——报告生成过程中AI发现关键洞察→提取到知识库→供场景5引用。这不是用户主动发起的动作，是报告生成过程的副产品。

## 三、操作流程

### 流程一：从空白开始生成报告

**适用场景**：全新撰写一份分析报告，无历史参考。

**操作步骤**：

1. 进入AI洞察首页，点击「从空白开始」卡片
2. 系统进入报告编辑页面，当前步骤为「需求收集」
3. 在左侧对话区输入分析需求，例如："分析乌鲁木齐6月流量运营情况，重点关注ARPU和DOU变化"
4. AI理解需求后在右侧需求概览区展示整理后的需求要点
5. AI自动推进到「数据准备」步骤，引导选择数据源：
   - 点击快捷栏「上传文件」→ 选择本地文件上传
   - 点击快捷栏「选择数据集」→ 从平台数据集中选取
   - 点击快捷栏「平台指标」→ 从指标体系中选择
   - 点击快捷栏「指标树」→ 浏览指标树选择指标
   - 点击快捷栏「选择客群」→ 从客群数据中选择
6. 数据确认后，AI推进到「大纲确认」步骤，生成报告大纲
7. 审阅大纲：
   - 点击「确认大纲」→ 推进到报告生成步骤
   - 点击「调整大纲」→ 在对话中说明调整要求，AI修改后重新确认
   - 点击「重新生成」→ AI重新生成大纲
8. AI自动推进到「报告生成」步骤，逐章节生成报告内容，右侧实时预览
9. 报告生成完毕，自动推进到「追问深化」步骤
10. 可选：对报告内容追问、深入分析
11. 点击快捷栏「进入审核」→ 推进到「审核定稿」步骤
12. 在审核定稿步骤中：
    - 逐章节审核，点击「通过」标记该章节已审核
    - 点击「一键全部通过」→ 标记所有章节为已审核
    - 对不满意的内容，直接在对话框中说明修改要求（如"第三章的ARPU分析加上环比数据"），AI会当场修改对应章节
    - 点击「继续追问」→ 返回追问深化步骤继续修改
13. 所有章节审核通过后，报告状态变为「已定稿」

### 流程二：月度经营分析报告（最核心场景，三条路径）

**适用场景**：每月/季度定期出经营分析报告。核心诉求：用旧报告的结构+新数据，快速出新一期报告。根据模板来源不同，有三条操作路径。

#### 路径A：模板复用（已保存过模板，最快捷）

1. 进入AI洞察首页，点击「从模板创建」卡片
2. 在弹出的模板选择面板中选择已保存模板（如"经营分析报告模板"）
3. 系统自动以模板结构初始化大纲
4. 上传本月新数据文件，系统自动匹配模板中的数据引用点
5. 确认大纲后，AI按模板结构+新数据生成报告
6. 追问深化关键发现，审核定稿导出

#### 路径B：导入旧报告（未保存模板但有旧文件）

1. 进入AI洞察首页，点击「导入模板分析」卡片
2. 系统进入报告编辑页面，模式为「导入报告」
3. **第一步：上传旧报告** → 在对话区中AI显示上传区域，点击选择文件上传旧报告文件（支持 .docx/.pdf/.txt 格式）
4. AI自动解析报告结构，展示识别出的章节列表
5. **第二步：确认大纲** → 审阅解析出的章节结构：
   - 点击「确认大纲，继续」→ 确认解析结果，进入数据准备
   - 点击「调整大纲」→ 在对话框中说明调整要求
   - 点击「重新上传报告」→ 放弃当前解析，重新上传
6. **第三步：提供新数据** → 上传新数据文件（操作同流程一第5步）
7. AI基于确认的大纲结构+新数据生成报告，进入报告生成步骤
8. 后续按流程一第9步起继续操作

> **注意**：导入模式的步骤流转为 需求收集→大纲确认→数据准备→报告生成，与标准流程不同。因为导入模式先从旧报告解析出结构（大纲），再填入新数据（数据准备），顺序与标准流程相反。导航条会按实际流转顺序高亮。

#### 路径C：定时自动生成（每月固定出，系统自动跑）

1. 首次配置：选择模板（如"经营分析报告模板"）
2. 设定生成周期（如每月5号）
3. 绑定平台指标数据源
4. 每月5号系统自动取数、匹配模板、生成报告初稿
5. 推送通知："6月经营分析报告已自动生成，请审核"
6. 打开报告，审核AI生成内容，追问深化关键发现
7. 审核定稿后导出

> **当前状态**：路径A/B已实现；路径C架构设计完成，定时任务和自动取数待开发。

**三条路径的共同逻辑**：旧结构+新数据=新报告。差异仅在"旧结构"的来源——已保存模板、上传旧文件、或绑定的定时模板。

### 流程三：指标异动分析（两种入口）

**适用场景**：指标出现异动，需要快速出一份归因分析报告。异动可能由用户主动发现，也可能由AI主动推送。两种入口后续的分析流程完全一致。

#### 入口A：用户主动发现

1. 在首页指标卡片或指标树中，点击「生成洞察报告」
2. 系统自动将该指标及其关联指标作为分析对象，进入对话界面
3. 系统询问报告范围（时间范围、区域范围、分析深度），用户确认
4. AI自动从平台指标体系匹配所需数据
5. 后续按「共同流程」继续

#### 入口B：AI主动推送

1. AI检测到指标异动（如ARPU环比下降超过阈值），推送通知至浮窗助手
2. 推送内容："全疆ARPU环比下降3.2%，可能原因：低价值套餐用户占比上升"
3. 点击通知，跳转至AI洞察报告编辑页面
4. 对话区自动预填充上下文（指标=ARPU、区域=全疆、时间=本月）
5. 后续按「共同流程」继续

#### 共同流程：归因分析

6. AI自动生成围绕指标异动的分析报告
7. 追问归因："为什么乌鲁木齐DOU下降了？"
8. AI归因分析并展示证据链（数据来源、计算口径、归因路径）
9. 归因结果嵌入报告
10. 自动匹配策略库，报告包含"建议策略"段落
11. 选择策略后一键创建策略调度工单，推送到网格人员执行
12. 审核定稿后导出

> **当前状态**：入口A部分实现（指标卡片入口待开发，六步流程已实现）；入口B架构设计完成，推送机制和策略联动待开发。

### 流程四：引用洞察生成报告

**适用场景**：从洞察知识库中发现有价值的洞察，基于洞察生成分析报告。

**操作步骤**：

1. 进入洞察知识库页面
2. 浏览或搜索洞察条目
3. 找到目标洞察，点击「引用此洞察」按钮
4. 系统跳转到AI洞察首页，自动进入报告编辑页面
5. 对话区自动注入洞察上下文：洞察结论、统计口径、关联指标、数据来源、验证状态
6. AI基于洞察内容推荐报告大纲
7. 后续按流程一第7步起继续操作

### 流程五：编辑已有报告

**操作路径A：从AI洞察首页**

1. 进入AI洞察首页，在「最近报告」区域查看最近操作过的报告
2. 点击报告条目，直接进入该报告的编辑页面
3. 草稿报告进入「追问深化」步骤
4. 待审核报告进入「审核定稿」步骤

**操作路径B：从报告中心**

1. 进入报告中心页面
2. 在对应Tab下找到目标报告：
   - 「草稿」Tab → 点击报告进入追问深化步骤
   - 「待审核」Tab → 点击报告进入审核定稿步骤
   - 「已定稿」Tab → 点击报告进入追问深化步骤（继续追问）
3. 继续编辑或审核

### 流程六：审核定稿

**适用场景**：报告生成完毕后进行最终审核确认。

**交互模型**（V4.0重构后）：

审核定稿**不是**一个"审批流"，而是"边看边改边确认"的自助审核模式：

| 场景 | 用户操作 | 系统行为 |
|------|---------|---------|
| 章节满意 | 点击该章节的「通过」按钮 | 标记该章节为已审核（绿色勾） |
| 全部满意 | 点击「一键全部通过」 | 标记所有章节为已审核，报告状态变为已定稿 |
| 局部不满意 | 在对话框中描述修改要求 | AI当场修改对应章节内容，修改后重新显示 |
| 整体需要继续完善 | 点击「继续追问」 | 返回追问深化步骤，可自由对话修改 |
| 再次完成修改 | 点击「进入审核」 | 回到审核定稿步骤 |

**关键变化**（相比旧版）：
- ❌ 删除「驳回至草稿」/「退回修改」——自助审核模式下无需退回，直接对话修改即可
- ✅ 新增「继续追问」——返回追问深化步骤继续完善
- ✅ 新增步骤感知对话——审核步骤中直接说修改要求，AI当场改，不需要退出审核再改

### 流程七：洞察自动沉淀（跨场景功能特性）

**说明**：这不是用户主动发起的独立操作流程，而是报告生成过程中的副产品功能，横跨场景1（月度经营分析）、场景3（从零创建专项）、场景5（引用洞察生成专题）。

**沉淀机制**：

1. 在报告生成过程中，AI识别到关键洞察（如"喀什地区6月新增用户环比异常下降42%"）
2. 在大纲预览消息中点击「提取洞察到知识库」
3. 系统自动提取洞察的结论、口径、关联指标、数据来源
4. 洞察沉淀到知识库，标注置信度和验证状态
5. 后续其他人员可通过「引用此洞察」直接复用已有分析结论（见流程四）
6. 报告完成时AI也会建议"以下洞察可以沉淀到知识库"，一键确认

### 流程八：浮窗助手页面上下文感知分析

**适用场景**：在任意运营页面浏览时，不想离开当前页面，直接打开浮窗即时提问。

**操作步骤**：

1. 在任意运营页面（如"流量运营>指标概览"），点击右下角浮窗助手图标
2. 浮窗自动感知当前页面上下文，头部显示："当前感知：流量运营 / 乌鲁木齐 / 日度指标"
3. 输入问题："DOU为什么降了？"
4. AI即时回答：基于当前页面指标数据分析下降原因
5. 追问："南疆四地州也有这个趋势吗？"
6. AI对比分析，发现仅喀什有类似趋势
7. 认为分析有价值时，点击浮窗中的「生成报告」按钮
8. 系统带着对话上下文跳转到AI洞察报告生成页面
9. 需求收集步骤自动填入"分析乌鲁木齐DOU下降原因"
10. 继续完成报告生成六步流程

> **当前状态**：浮窗助手架构设计已完成（三层分离+上下文感知模型），上下文注入机制待开发。

## 四、各页面详细操作

### 3.1 AI洞察首页

#### 开始页

进入 `/workspace/ai-insight` 后显示开始页，包含四个入口卡片：

| 卡片 | 说明 |
|------|------|
| 从空白开始 | 新建空白报告，从需求收集步骤开始 |
| 从模板创建 | 选择已保存的模板，基于模板结构生成报告 |
| 导入模板分析 | 上传历史报告文件，解析结构后用新数据生成新报告 |
| 最近报告 | 显示最近3条操作过的报告，点击直接进入编辑 |

#### 报告编辑页面

报告编辑页面为左右分栏布局：

- **左侧（60%）**：AI对话区，包含步骤导航条、对话消息列表、快捷操作栏、输入框
- **右侧（40%）**：上下文面板，根据当前步骤展示不同内容：
  - 需求收集 → 需求概览
  - 数据准备 → 数据探查画像
  - 大纲确认 → 大纲预览
  - 报告生成 → 报告实时预览
  - 追问深化 → 报告预览
  - 审核定稿 → 报告预览+审核操作

##### 步骤导航条

顶部显示六个步骤节点，当前激活步骤高亮，已完成步骤显示绿色勾。导航条反映实际流转顺序（导入模式下顺序与标准模式不同）。

##### 快捷操作栏

快捷栏根据当前步骤动态显示：

| 步骤 | 可用快捷按钮 |
|------|------------|
| 需求收集 | 上传文件、选择数据集、平台指标、指标树、选择客群 |
| 数据准备 | 上传文件、选择数据集、平台指标、指标树、选择客群、确认数据 |
| 大纲确认 | 确认大纲、调整大纲、重新生成 |
| 报告生成 | （等待生成，无快捷按钮） |
| 追问深化 | 进入审核、嵌入报告、深入归因 |
| 审核定稿 | 一键全部通过、继续追问 |

##### 对话输入框

支持自由文本输入，AI根据当前步骤感知用户意图：

| 步骤 | 输入示例 | AI行为 |
|------|---------|--------|
| 需求收集 | "分析乌鲁木齐6月流量" | 识别分析主题，整理需求 |
| 数据准备 | "我上传了销售数据" | 引导数据格式确认 |
| 大纲确认 | "把第三章拆成两个" | 调整大纲结构 |
| 报告生成 | （任意输入） | 提示等待生成完成 |
| 追问深化 | "ARPU为什么下降了？" | 自由分析对话 |
| 审核定稿 | "第三章加上环比数据" | 当场修改对应章节 |

##### 报告名称编辑

报告标题区域可直接点击编辑，修改后自动保存。

### 3.2 洞察知识库

#### 列表视图

- 展示所有已沉淀的洞察条目
- 每条洞察显示：洞察标题、结论摘要、关联指标数、置信度、验证状态
- 支持按分类、置信度、验证状态筛选
- 支持关键词搜索

#### 洞察详情

点击洞察条目展开详情，显示：
- **结论**：洞察的核心发现
- **统计口径**：数据计算方式和来源
- **关联指标**：与洞察相关的指标列表
- **数据来源**：洞察所基于的数据源
- **验证状态**：已验证/未验证/验证失败

#### 引用此洞察

点击「引用此洞察」按钮 → 自动跳转到AI洞察首页 → 报告编辑页面自动注入洞察上下文 → AI基于洞察推荐报告大纲。

## 七、常见问题

### Q1：导入报告时，步骤顺序为什么和标准流程不同？

导入模式是"先有结构再填数据"，所以流程是 需求收集→大纲确认→数据准备→报告生成。标准模式是"先准备数据再出大纲"，流程是 需求收集→数据准备→大纲确认→报告生成。导航条会按实际流转顺序显示。

### Q2：审核定稿时发现内容不满意怎么办？

直接在对话框中说修改要求即可，例如"第三章的ARPU分析加上环比数据"，AI会当场修改对应章节。不需要退出审核步骤，也不需要"退回"或"驳回"。修改满意后再点「通过」或「一键全部通过」。

### Q3：定稿后的报告还能修改吗？

可以。在报告中心找到已定稿的报告，点击进入后会在「追问深化」步骤打开，可以继续对话修改。修改完成后再次进入审核定稿。

### Q4：洞察知识库的"引用此洞察"做了什么？

点击后会跳转到AI洞察报告编辑页面，自动将洞察的结论、统计口径、关联指标、数据来源等信息注入对话上下文，AI会基于这些信息推荐报告大纲。

### Q5：浮窗助手和报告生成页面是什么关系？

浮窗助手是轻量级即时问答入口（右下角图标），支持快问快答、指标解读、快捷触发报告生成。报告生成页面是深度结构化交互页面。浮窗可以"升级"到报告生成页面（带着对话上下文跳转），但两者不互相替代。

### Q6：报告可以导出吗？

已定稿的报告支持导出。在报告中心找到已定稿报告，点击「导出」即可。

### Q7：上传的数据文件有什么格式要求？

支持 CSV、Excel（.xlsx/.xls）、JSON 格式。系统会自动解析文件结构并进行数据探查，生成数据画像供确认。
