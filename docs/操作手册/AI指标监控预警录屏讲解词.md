# AI指标监控预警录屏讲解词

## 一、准备工作

关掉所有软件，只留浏览器和录屏软件，打开系统页面用区公司/分公司（地州公司）运营人员角色登录。

## 二、开始录屏

大家好：

现在从工作台的角度介绍一下新疆市场运营平台AI指标监控预警场景的相关操作，完整演示AI预警规则的查看、配置、监测、确认与闭环管理的全过程。

AI指标监控预警是平台"AI+运营"体系的重要组成部分，由AI对核心经营指标进行账期级自动监测、自动判定、自动预警，并对预警结果配套人工确认闭环，实现指标异动从"被动发现"到"主动预警、精准处置"的转变。

AI指标监控预警承接集团智能预警验收要求，核心解决四个问题：

1. 监控范围是否覆盖核心场景指标：覆盖流量、存量、细分市场核心场景指标，无关键指标缺失；
2. 预警规则是否可灵活配置：支持按阈值、同比/环比等口径配置预警规则，规则可新增、修改、禁用；
3. 预警可触达：预警信息可通过平台消息、短信、小屏推送等渠道下发，并触达至相关负责人；
4. 是否支持指标下钻定位异常：预警指标可下钻至细分维度（省-市-县-格、客群、产品），定位具体异常点。

AI指标监控预警包含规则监控总览（规则检索、多视角汇总、新增与启停管理）和规则详情（账期级监测、预警确认闭环）两部分功能，下面逐一介绍。

## 第一部分：工作台·AI指标监控预警

### 1、预警规则总览

点击顶部菜单"工作台"，在"洞察管理-预警管理"下点击"AI指标监控预警"，进入规则列表页。

列表页集中管理平台所有由AI自动判定的指标预警规则，每条规则清晰展示：监测指标名称、业务场景、预警粒度、预警范围、当前判定条件（带AI标识，说明该判定由AI自动学习产出）、准确率、误报次数、总预警次数、状态（启停开关）、操作（详情）。

从规则列表可以看到，平台监控范围已覆盖流量运营、存量运营、细分市场三大公众市场核心场景，如当月拍照客户价值保有率、月通信服务收入环比、全球通保有率等关键指标均在监测之列；同时面向集团侧区域经营，覆盖5G升级场景、宽带续约场景、携出预警场景等全国重点场景，核心场景指标无缺失。

页面顶部为搜索筛选区：

- 业务场景筛选：支持按"全国/公众市场"三级业务场景结构逐级筛选（全国→华南/华东/西南→5G升级场景、客户维系场景等；公众市场→流量运营/存量运营/细分市场→流量运营、中高端运营、离网维系等）；
- 指标名称搜索：支持输入指标名称关键字模糊匹配；
- 展示形式切换：提供不汇总、按指标汇总、按区域汇总三种视角。不汇总逐条查看全部规则；按指标汇总将同一指标在多个范围的预警合并展示，便于从指标维度总览监控面；按区域汇总将同一区域内多个指标的预警合并，便于从区域维度总览预警态势。

注释：页面定位在AI指标监控预警列表页，演示检索、筛选与展示形式切换，待介绍结束后进入新增预警规则功能。

### 2、新增预警规则

点击"新增"按钮，弹出新增预警规则弹窗。

新增弹窗包含四个必填要素：业务场景、预警粒度、指标、预警范围，这是AI预警规则的"四维建模"，通过场景×粒度×指标×范围的组合，实现预警规则的灵活配置与精准定位。

1. 业务场景：必填，采用三级联动树形选择。一级分"全国"与"公众市场"，"全国"下挂华南/华东/西南等区域域，"公众市场"下挂流量运营/存量运营/细分市场等业务域，逐级联动展开到具体业务场景，所见即所得；
2. 预警粒度：必填，支持省份、地市、区县、网格四级，对应集团"省-市-县-格"的下钻粒度要求；
3. 指标：必填，从平台统一指标字典中选择，支持关键字搜索，确保监控对象口径标准、来源统一；
4. 预警范围：必填，随预警粒度自动联动——选省份级即对全疆（新疆维吾尔自治区）监测，选地市级联动出乌鲁木齐、克拉玛依等16个地市分公司，选区县、网格级则进一步细化到具体区县与网格单元，异常可定位到细分维度。

新规则的判定条件由AI自动学习生成：平台AI基于历史账期数据，按指标特性自动归纳环比降幅、阈值等判定口径，无需人工编写复杂规则；规则创建后立即启用生效，支持随时停用、重新配置，实现"规则可新增、修改、禁用"的灵活管理。

注释：页面定位在新增预警规则弹窗，演示业务场景树选择、粒度与范围联动，待介绍结束后进入规则启停管理功能。

### 3、规则启停管理

关闭新增弹窗回到规则列表页，新创建的规则已出现在监控列表中并处于启用状态。

规则状态开关支持随时启用或停用：停用后该指标即暂停AI监测与预警，启用后恢复监测，方便业务在不同阶段按需管理监控面；同时列表持续展示AI判定的准确率与误报次数，随确认闭环不断刷新，客观反映AI判定模型的实际效果。

注释：页面定位在规则列表页，演示状态开关启停，待介绍结束后进入规则详情功能。

### 4、规则详情与账期监测

点击规则右侧"详情"按钮，进入该规则的详情页。

详情页上方为指标基础信息卡，完整展示该规则的监控对象：指标名称、业务场景、预警粒度、预警范围、当前判定条件（AI标识）、准确率、误报次数、总预警次数、状态，与列表配置一一对应。

下方为预警情况明细表，按指标账期逐期记录执行结果：指标账期、指标数值、更新时间、判定条件（AI标识）、判定条件说明、是否执行指标预警、预警说明、是否误判、操作。每一条记录均完整呈现当期AI的判定依据与说明，做到"AI为什么预警、依据是什么"全程可解释、可留痕。

触发预警的账期，系统即"执行指标预警"，预警信息经平台统一触达通道，以平台消息、短信、小屏推送等方式下发至对应区域/网格负责人，实现预警"可触达、有人看、有人管"；未满足判定条件的账期如实记录为"已执行未预警"，保证监测过程完整可信。

注释：页面定位在规则详情页，演示基础信息与账期级监测明细，待介绍结束后进入预警确认闭环功能。

### 5、预警确认闭环

对于AI触发的预警，平台配套人工确认闭环。

在最新账期（待确认）记录行点击"确认"，弹出确认预警弹窗：上方完整呈现本次预警依据（AI标识），包括指标账期、指标数值、判定条件与判定条件说明；下方请负责人判断本次预警是否为误判，在"未误判/误判"中选择后点击确认，系统即记录确认结果及确认人、确认时间。

选择"未误判"，代表该预警真实有效，将指导相关区域负责人及时开展干预处置；选择"误判"，该信息将自动沉淀为AI模型的反馈样本，用于持续优化判定条件——列表页的准确率、误报次数即由此累积，实现"AI越用越准"。

已确认的记录可通过"查看"按钮回溯预警依据与确认信息（是否误判、确认人、确认时间），全流程可审计、可追溯。

注释：页面定位在规则详情页，演示确认预警与查看预警弹窗，待介绍结束后进入收尾总结。

## 三、收尾总结

以上是AI指标监控预警场景的相关操作介绍。

AI指标监控预警通过"规则总览"实现流量、存量、细分市场核心场景指标的统一监控与多视角检索，通过"新增规则"实现场景×粒度×指标×范围四要素灵活配置、AI自动学习判定条件，通过"账期监测"实现指标异动的自动识别与多渠道触达，通过"确认闭环"实现预警结果的复核反馈与AI模型的持续优化。

对照集团验收要求：监控范围覆盖流量、存量、细分市场核心场景指标，无关键指标缺失；规则支持按阈值、同比/环比口径配置，可新增、修改、禁用；预警经平台消息、短信、小屏推送等渠道触达相关负责人；指标粒度覆盖省-市-县-格并可细化到业务场景维度，异常可下钻定位——四项要求全部落地。

平台通过AI指标监控预警的建设，实现了指标异动从"被动发现"到"主动预警、精准处置"的运营闭环，让AI监测结果可信、可用、可进化，支撑市场运营平台持续向智能化演进。
