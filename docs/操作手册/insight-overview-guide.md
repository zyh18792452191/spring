# 洞察总览页面说明文档

## 页面说明
洞察总览页面是一个**全量场景指标树集合**展示页面，用于展示各个业务场景下的指标树结构。

## 页面位置
`src/app/portal/capability/insight/overview/page.tsx`

## 页面功能

### 1. 核心功能
- 以卡片形式展示全量场景指标树（4列网格布局）
- 每个卡片包含指标树的缩略图、标题、描述
- 按业务场景分类筛选指标树
- 按归属区域筛选指标树（全国、集团、31个省份）
- 支持搜索指标树名称、指标
- 指标预览区域默认收起，点击展开按钮可查看前3个指标
- 指标树节点支持折叠和展开
- 支持分页功能，每页显示12个卡片

### 2. 分页功能
- 当指标树数量超过12个时，自动显示分页组件
- 每页显示12个卡片（3行 × 4列）
- 支持上一页、下一页和直接跳转到指定页
- 切换业务场景或归属区域时，自动重置到第一页

### 3. 归属区域筛选
- 支持33个归属区域选项：全国（默认）+ 集团 + 31个省份
- 省份列表：北京、天津、河北、山西、内蒙古、辽宁、吉林、黑龙江、上海、江苏、浙江、安徽、福建、江西、山东、河南、湖北、湖南、广东、广西、海南、重庆、四川、贵州、云南、西藏、陕西、甘肃、青海、宁夏、新疆
- 使用下拉选择器实现，位置在搜索筛选栏中
- 默认显示"全国"，展示所有归属区域的指标树
- 选择特定归属区域后，只展示该归属区域的指标树
- 归属区域和业务场景筛选可组合使用

### 3. 卡片结构
每个指标树卡片包含以下内容：
- **缩略图区域**：显示指标树的可视化缩略图（高度 144px / h-36）
- **CardHeader**：
  - 标题行：标题（左对齐）+ "查看详情"按钮（右对齐）
  - 描述行：指标树的简要说明
- **展开/收起按钮**：点击可展开或收起指标预览区域（高度 h-6）
- **指标预览区域**：展开后显示前3个指标节点，支持节点折叠/展开（最大高度 112px / h-28）
- **注意**：已移除独立的"查看详情"区域，整合到标题行

### 4. 布局规格
- **网格布局**：响应式网格
  - 移动端：1列
  - 平板端：2列
  - 桌面端：4列
- **卡片间距**：gap-4（16px）
- **卡片圆角**：默认 Card 组件样式
- **分页规格**：
  - 每页显示：12个卡片（3行 × 4列）
  - 分页器位置：卡片网格下方
  - 页码按钮尺寸：w-7 h-7（28px × 28px）

### 5. 卡片尺寸（优化后）
- **缩略图区域**：h-36（144px）
- **缩略图图标**：h-10 w-10（40px）
- **场景标签**：h-5.5，字号 text-[10px]
- **指标数量标签**：h-5.5，字号 text-[10px]
- **CardHeader 内边距**：py-2 px-3
- **标题行布局**：flex 布局，标题左对齐，"查看详情"按钮右对齐
- **标题**：字号 text-xs，flex-1，最多1行
- **查看详情按钮**：h-6，字号 text-[10px]，flex-shrink-0
- **描述**：字号 text-[9px]，最多2行
- **展开/收起按钮**：h-6（24px），字号 text-[9px]
- **指标预览区域**：max-h-28（112px）
- **指标节点**：
  - 指标名称：text-[10px]
  - 指标编码：text-[8px]
  - 指标值Badge：h-4，text-[8px]
  - 节点图标：h-2.5 w-2.5

### 6. 分页数据
- 当前示例数据：15个指标树卡片
- 第一页：12个卡片
- 第二页：3个卡片
- 总页数：2页

页面包含以下业务场景分类：
- **全部** - 展示所有业务场景的指标
- **中高端客户运营** - 8个指标
- **国际业务运营** - 6个指标
- **离网维系** - 10个指标
- **用量运营** - 7个指标
- **融合运营** - 5个指标
- **细分市场运营** - 8个指标

### 7. 主要指标
默认展示的核心指标包括：
- 拍照中高端价值保有率
- 拍照中高端规模保有率
- 当月全量离网客户数
- 当月拍照中高端离网客户数
- 超套客户规模
- 宽移融合率

## 数据结构

### MetricTreeCard（指标树卡片）
```typescript
interface MetricTreeCard {
  id: string;              // 卡片ID
  title: string;           // 指标树标题
  description: string;     // 描述
  thumbnail: string;       // 缩略图URL
  scenario: string;        // 所属业务场景ID
  metricsCount: number;    // 指标数量
  region: string;          // 归属区域ID（all/group/省份代码）
  metrics: MetricTreeNode[]; // 指标树完整数据（用于详情页）
}
```

interface MetricTreeNode {
  id: string;              // 节点ID
  name: string;            // 指标名称
  code: string;            // 指标编码
  value?: string;          // 指标值
  children?: MetricTreeNode[]; // 子指标
}
```

## 自定义配置

### 添加新的指标树卡片
在 `metricTreeCards` 数组中添加新的卡片对象：

```typescript
{
  id: 'card-1',
  title: '中高端客户运营指标树',
  description: '中高端客户的保有率、离网等关键指标',
  scenario: '中高端客户运营',
  metricsCount: 15,
  root: {
    id: 'root',
    name: '中高端客户运营',
    code: 'PREMIUM_CUSTOMER',
    children: [
      {
        id: 'node-1',
        name: '规模保有率',
        code: 'RETENTION_RATE',
        children: [
          { id: 'node-1-1', name: '拍照中高端规模保有率', code: 'RETENTION_RATE_PHOTO' }
        ]
      }
    ]
  }
}
```

在 `scenarioTabs` 数组中添加新的场景标签：

```typescript

  id: 'new-scenario',

## 技术说明

- **布局**：使用 portal 布局（只有顶部导航，无左侧菜单）
- **组件**：使用 shadcn/ui 组件库
- **状态管理**：使用 React useState 管理展开节点和选择场景
- **图标**：使用 lucide-react 图标库
- **类型**：TypeScript 类型安全
- **热更新**：支持热更新，修改代码后自动刷新

## 备注

- 当前使用模拟数据，实际使用时需要从后端API获取数据
- 页面路由位于 `/portal` 路径下，与门户首页、离网维系页面布局一致
- 指标树支持多层级嵌套，理论上无限层级
- 搜索功能需要根据实际需求实现模糊匹配逻辑
