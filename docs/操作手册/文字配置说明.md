# 文字配置说明

## 概述

本项目使用集中化的文字配置系统，所有页面显示的文字都在 `src/config/textConfig.ts` 文件中统一管理。

## 使用方法

### 1. 修改文字

1. 打开 `src/config/text.ts` 文件
2. 找到需要修改的文字
3. 修改对应的值
4. 刷新浏览器，页面会自动更新

### 2. 示例

假设要将"市场运营平台"改为"数智运营平台"：

1. 打开 `src/config/textConfig.ts`
2. 找到第 12 行：
```typescript
pageTitle: '市场运营平台',
```
3. 修改为：
```typescript
pageTitle: '数智运营平台',
```
4. 保存文件
5. 刷新浏览器

### 3. 配置文件结构

```typescript
export const textConfig = {
  nav: {
    breadcrumbHome: '首页',
    breadcrumbCurrent: '工作台',
    pageTitle: '市场运营平台',
  },
  churnRetention: {
    tabs: {
      overview: '概览',
      allChurn: '当月全量客户离网客户数',
      // ...
    },
    // ...
  },
};
```

## 优势

✅ 集中管理：所有文字都在一个文件中，易于查找和修改  
✅ 快速修改：不需要修改组件代码，直接修改配置即可  
✅ 易于维护：可以快速批量修改多个页面上的相同文字  
✅ 减少错误：避免在代码中直接硬编码文字，降低出错率  

## 添加新文字

如果需要添加新的文字配置：

1. 在 `src/config/textConfig.ts` 中添加对应的键值对
2. 在组件中通过 `textConfig.xxx.xxx` 引用
3. 保存并刷新

## 示例

在组件中使用配置文件中的文字：

```tsx
import { textConfig } from '@/config/textConfig';

// 使用
<h1>{textConfig.nav.pageTitle}</h1>
<p>{textConfig.churnRetention.analysisPanel.title}</p>
```
