## 二、商机概览

### 2.1 模块定位

商机概览嵌入在「流量运营」页面的「商机总览」Tab 内，为不同角色提供差异化的数据视图。用户通过顶部角色Tab切换查看不同维度的商机信息，每个角色看到的数据范围、图表形态和操作入口完全不同。

### 2.2 角色Tab切换

页面顶部提供4个角色Tab，每个Tab包含角色图标、角色名称和简短描述：

| Tab | 图标 | 名称 | 描述 | 核心关注点 |
|-----|------|------|------|-----------|
| 1 | Crown | 领导人 | 宏观决策 | 全局指标、区域对比、趋势洞察 |
| 2 | Settings | 运营人员 | 商机管理 | 商机流转效率、待处理工单、清洗质量 |
| 3 | Shield | 网格长 | 网格管理 | 人员调度、分配状态、逾期管控 |
| 4 | UserCheck | 网格人员 | 抢单执行 | 个人绩效、抢单池、待处理工单 |

**交互规则**：
- 默认展示「领导人」Tab
- 点击Tab即切换角色视图，不刷新页面
- 角色Tab右侧显示当前区域选择范围

### 2.3 领导人视角

#### 2.3.1 核心KPI卡片（4个）

| 指标 | 说明 | 趋势展示 |
|------|------|----------|
| 商机总量 | 当前区域下全部商机数量 | 环比变化百分比，上升绿色，下降红色 |
| 商机执行率 | 已处理商机数/总商机数 | 环比变化pp，上升绿色 |
| 商机转化率 | 已转化商机数/已处理商机数 | 环比变化pp，上升绿色 |
| 逾期商机数 | 超过处理时效仍未完成的商机数 | 环比变化百分比，下降为好（绿色） |

#### 2.3.2 商机趋势图

- **图表类型**：组合图（ComposedChart）
- **展示维度**：近6个月
- **数据系列**：
  - 柱状图：商机量（左Y轴）
  - 折线图1：执行率（右Y轴，%）
  - 折线图2：转化率（右Y轴，%）
- **交互**：支持Tooltip悬浮查看具体数值

#### 2.3.3 商机分类占比

- **图表类型**：环形饼图
- **分类维度**：三级分类
  - 流量达量预警（风险预警类）
  - 特定内容高频访问（价值提升类）
  - 地板价套餐查询（价值提升类）
  - 零流量使用预警（生命周期类）
- **标签**：饼图标签显示"三级分类名 占比%"
- **图例**：下方列表显示各三级分类名称、所属一级分类（括号标注）、具体条数

#### 2.3.4 区域商机量排名

- **图表类型**：横向条形图（BarChart，layout=vertical）
- **数据维度**：辽宁省14个地市
- **排序**：按商机量降序
- **视觉区分**：前3名深色高亮，其余浅色

#### 2.3.5 下级区域关键指标

- **展示形式**：数据表格
- **列定义**：

| 列名 | 说明 | 条件样式 |
|------|------|----------|
| 排名 | 按商机量降序排列 | 前3名圆形徽章蓝色高亮 |
| 区域 | 地市名称 | - |
| 商机量 | 该区域商机总数 | - |
| 执行率 | 已处理/总数 | ≥75%绿色，≥70%黄色，<70%红色 |
| 转化率 | 已转化/已处理 | ≥40%绿色，≥35%黄色，<35%红色 |
| 逾期数 | 逾期商机条数 | - |

#### 2.3.6 预警概览

- **展示形式**：4个色块卡片

## 三、商机管理

### 3.1 模块定位

商机管理位于「我的工作台」下，提供商机的全生命周期管理能力。支持单客户商机和客群商机两种类型，通过Tab切换查看和管理。

### 3.2 页面结构

页面顶部为标题栏+新增按钮，下方为Tab切换（单客户商机/客群商机），每个Tab包含搜索筛选区和数据列表区。

### 3.3 单客户商机

#### 3.3.1 搜索筛选区

搜索区采用4列网格布局，包含以下筛选条件：

| 筛选项 | 控件类型 | 说明 |
|--------|----------|------|
| 商机ID | 输入框 | 模糊匹配 |
| 商机分类 | 三级联动选择器 | 一级→二级→三级联动，选择上级自动重置下级 |
| 商机源 | 下拉选择 | CRM系统/营销活动平台/外呼系统/线上渠道/线下营业厅/代理商系统/微信小程序/企业微信 |
| 手机号 | 输入框 | 模糊匹配 |
| 评级 | 下拉选择 | 高/中/低 |
| 状态 | 下拉选择 | 10种状态 |
| 区域 | 输入框 | 模糊匹配（市/区/网格关键词） |
| 日期 | 日期范围选择器 | 开始日期-结束日期 |

**操作按钮**：重置（清空所有条件）、搜索（触发筛选）

#### 3.3.2 数据列表

**列表信息栏**：显示"共 X 条商机"

**列定义**：

| 列名 | 宽度 | 说明 |
|------|------|------|
| 商机ID | 9% | 蓝色字体可点击 |
| 商机分类 | 14% | 完整三级路径（一级/二级/三级） |
| 商机源 | 7% | 来源名称 |
| 区域信息 | 11% | 格式：**市**区**网格 |
| 评级 | 5% | Badge：高=红，中=橙，低=绿 |
| 状态 | 7% | Badge，颜色见状态配置 |
| 客户 | 14% | 姓名+脱敏手机号 |
| 商机采集时间 | 11% | yyyy-MM-dd HH:mm格式 |
| 处理时效 | 7% | 小时数+h，无则显示"-" |
| 操作 | 7% | 按状态动态显示 |

#### 3.3.3 状态定义与操作按钮

| 状态码 | 状态名 | Badge颜色 | 可用操作 |
|--------|--------|-----------|----------|
| PENDING_DISPATCH | 待派发 | 黄色 | 详情、编辑、手动派发、删除 |
| PENDING_GRAB | 待抢单 | 橙色 | 详情、编辑、抢单、删除 |
| DISPATCHED | 已派发 | 蓝色 | 详情、转派 |
| GRABBED | 已抢单 | 青色 | 详情、开始处理、转派 |
| ACCEPTED | 已接收 | 靛蓝色 | 详情、开始处理、转派 |
| PROCESSING | 处理中 | 紫色 | 详情、记录结果、转派 |
| CONVERTED | 已转化 | 绿色 | 详情 |
| FAILED | 已失败 | 红色 | 详情、回捞、删除 |
| RECYCLED | 已回收 | 灰色 | 详情 |
| EXPIRED | 已失效 | 石色 | 详情、删除 |

**通用操作按钮**：详情（所有状态可见）

**关键操作说明**：
- **手动派发**：将待派发商机指定给具体人员
- **抢单**：网格人员主动认领待抢单商机
- **转派**：将已派发/已抢单/已接收/处理中的商机转给其他人员
- **开始处理**：已抢单/已接收商机开始执行
- **记录结果**：处理中商机记录处理结果（转化/失败）
- **回捞**：对已失败商机重新投入处理流程
- **删除**：需二次确认

#### 3.3.4 新增商机

**入口**：列表页右上角「新增商机」按钮

**表单字段**：

| 字段 | 控件类型 | 必填 | 说明 |
|------|----------|------|------|
| 商机分类 | 三级联动选择器 | 是 | 一级→二级→三级联动 |
| 商机源 | 下拉选择 | 是 | 同列表筛选源列表 |
| 评级 | 下拉选择 | 是 | 高/中/低 |
| 目标客户类型 | 单选 | 是 | 单客户/客群 |
| 手机号 | 输入框 | 条件必填 | 当目标客户类型=单客户时必填 |
| 客群标签 | 标签选择器 | 条件必填 | 当目标客户类型=客群时，弹出标签关联弹窗选择 |
| 商机录入原因 | 文本域 | 是 | 描述商机背景和处理建议 |

**表单校验**：
- 三级分类必须选择到最末级
- 手机号格式校验
- 录入原因不能为空

| PENDING_DISPATCH | 待派单 | 黄色 | 详情、人工派单 |
| DISPATCHED | 已派单 | 蓝色 | 详情、转派 |
| COMPLETED | 已完成 | 绿色 | 详情 |
| EXPIRED | 已失效 | 石色 | 详情 |

- 待派单状态的客群商机操作栏显示「人工派单」按钮

## 五、区域筛选机制

### 5.1 辽宁省市网格体系

- **省级**：辽宁省（code: 210000）
- **市级**：14个地市（沈阳、大连、鞍山、抚顺、本溪、丹东、锦州、营口、阜新、辽阳、盘锦、铁岭、朝阳、葫芦岛）
- **网格级**：每个地市下辖多个网格

### 5.2 区域信息展示格式

所有涉及区域信息的展示统一采用 `**市**区**网格` 格式，例如：
- 沈阳市沈河区南塔网格
- 大连市西岗区北京街道网格
- 鞍山市铁东区站前网格

### 5.3 区域筛选组件

- **商机概览**：使用 `LiaoningRegionSelector` 组件，支持全省/市/网格三级切换
- **商机管理**：使用输入框模糊匹配区域关键词

## 六、状态流转规则

### 6.1 单客户商机状态流转

```
待派发 ──手动派发──→ 已派发 ──转派──→ 已派发
  │                     │
  │                     └──→ 待抢单 ──抢单──→ 已抢单 ──开始处理──→ 处理中
  │                                                          │
  └──删除                    已接收 ──开始处理──→ 处理中 ──记录结果──→ 已转化
                                                        │
                                          转派 ──→ 已派发  └──→ 已失败 ──回捞──→ 待派发
                                                        │              └──删除──→ (移除)
                                          已回收 ←── 超时回收
                                          已失效 ←── 超时未处理
```

### 6.2 客群商机状态流转

```
待派单 ──人工派单──→ 已派单 ──转派──→ 已派单
                        │
                        └──→ 已完成
                        └──→ 已失效（超时）
                        └──→ 已废弃（人工废弃）
```
