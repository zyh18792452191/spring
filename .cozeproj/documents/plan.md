# AI指标监控预警 功能实现计划

## 概述

在「工作台 → 洞察管理 → 预警管理」下新增 **AI指标监控预警** 菜单（路径 `/workspace/insight/alert/ai-monitor`），提供指标级 AI 监控预警的规则配置与预警结果闭环管理：列表筛选查看（支持按指标/按区域汇总）、新增预警规则（业务场景三级级联 + 预警粒度与范围联动）、规则详情与"确认预警 / 查看预警"操作。纯前端模拟数据实现，遵循平台既有 shadcn/ui + Tailwind 规范。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 框架 | Next.js 16 App Router + React 19 + TS | 平台既有技术栈 |
| UI | shadcn/ui（Dialog/Select/Table/Switch/Badge/RadioGroup）+ Tailwind 4 | 与现有预警管理页面一致 |
| 数据 | 本地 mock 数据文件（types + 常量 + 列表/明细） | 原型阶段无后端，参考现有 config/list 页做法 |
| 路由 | 列表 `/workspace/insight/alert/ai-monitor`；详情 `?id=` 查询参数 | 页面规格规范：详情页用查询参数 |
| 视觉 | 全局主题变量 + AI 紫色 Badge 惯例 | DESIGN.md 既有规范 |

## 功能模块

### 1. 数据与类型（`ai-monitor/data.ts`）

```ts
// 预警粒度
type AlertGranularity = '省份' | '地市' | '区县' | '网格';
// 展示形式
type ViewMode = 'none' | 'byIndicator' | 'byRegion'; // 不汇总/按指标汇总/按区域汇总
// 列表规则行
interface AiMonitorRule {
  id: string;
  indicator: string;              // 指标名称（如 当月拍照客户价值保有率）
  scenePath: string[];            // 业务场景三级路径（如 ['公众市场','流量运营','流量运营']）
  granularity: AlertGranularity;  // 预警粒度
  scope: string;                  // 预警范围（如 阿克达拉网格）
  condition: string;              // 当前判定条件（AI生成，如 环比降幅超过10%）
  accuracy: number | null;        // 准确率（%）
  falseCount: number;             // 误报次数
  totalCount: number;             // 总预警次数
  enabled: boolean;               // 状态开关
}
// 详情页预警明细行
interface AlertRecord {
  id: string;
  period: string;        // 指标账期（如 2026-08）
  value: string;         // 指标数值（如 3.14%）
  updatedAt: string;     // 更新时间
  condition: string;     // 判定条件
  ai: boolean;           // 是否 AI 生成
  conditionDesc: string; // 判定条件说明
  execStatus: 'noAlert' | 'alerted'; // 是否执行指标预警
  alertDesc: string;     // 预警说明
  misjudge: 'pending' | 'no' | 'yes'; // 是否误判（待确认/未误判/误判）
  confirmUser?: string; confirmTime?: string; // 确认人/时间（已确认才有）
}
```

**业务场景树**（三级，来自原型截图，检查现有原型无此结构 → 新建）：
- 全国 → 华南（5G升级场景/客户维系场景）、华东（宽带续约场景）、西南（携出预警场景）
- 公众市场 → 流量运营（流量运营）、存量运营（中高端运营/离网维系/家庭运营）、细分市场（国际运营）

**预警粒度与范围联动**（参考 `src/data/provinces.ts` 新疆运营体系）：
- 省份 → 新疆维吾尔自治区
- 地市 → 16 地市分公司（乌鲁木齐、克拉玛依…石河子）
- 区县/网格 → 对应下级行政区/网格候选（含演示网格：阿克达拉网格、夏塔网格等）

**指标字典**：约 20+ 条指标（含截图中的 当月拍照客户价值保有率、月通信服务收入环比、5G登网用户数等），支持名称搜索。

**模拟数据**：列表 5 条规则（覆盖 阿克达拉网格/夏塔网格/乌鲁木齐 等范围）、详情页 3 条明细（待确认/未误判/误判 各态），口径与字段描述以代码注释说明。

### 2. 业务场景树选择器（`components/BusinessSceneSelect.tsx`）

- Popover + 三级列联（左侧一级 → 中间二级 → 右侧叶子场景），选中叶子后回填完整路径 `公众市场/流量运营/流量运营`
- 受控组件：`value: string[] | null` + `onChange(scenePath)`
- 供列表筛选与新增弹窗复用（筛选场景单选叶子）

### 3. 列表页（`page.tsx`）

- 顶部筛选栏：业务场景树下拉、指标名称搜索框、展示形式下拉（不汇总/按指标汇总/按区域汇总）、重置/搜索按钮；右上「+新增」按钮
- 汇总逻辑：按指标汇总=同指标多范围合成一行（范围列显示"N 个范围"，误报/总预警求和、准确率取均值）；按区域汇总=同范围多指标合成一行（指标列显示"N 个指标"）
- 表格列：指标名称 / 业务场景 / 预警粒度 / 预警范围 / 当前判定条件（紫色 AI Badge）/ 准确率 / 误报次数 / 总预警次数 / 状态（Switch 启停）/ 操作（详情）
- 分页：每页 10 条，显示"共 N 项数据"，页码切换
- 空态：无匹配数据显示空表格占位

### 4. 新增弹窗（`components/CreateAlertDialog.tsx`）

- 4 个必填字段：业务场景（树选择）、预警粒度（Select：省份/地市/区县/网格）、指标（可搜索下拉单选）、预警范围（下拉随粒度联动 + 搜索框过滤）
- 全部为空时提示先选业务场景；必填缺失则按钮置灰或校验提示
- 确认后生成新规则行并插入列表（默认启用、0 误报、判定条件自动生成）

### 5. 详情页（`detail/page.tsx`，`?id=` 参数）

- 返回按钮（router.back 或回列表）
- 指标基础信息卡：指标名称、业务场景、预警粒度、预警范围、当前判定条件（AI）、准确率、误报次数、总预警次数、状态
- 预警情况表格列：指标账期 / 指标数值 / 更新时间 / 判定条件(AI) / 判定条件说明 / 是否执行指标预警(已执行未预警/已执行已预警) / 预警说明 / 是否误判(待确认/未误判/误判) / 操作
- 操作列：待确认行 →「确认」；已确认行 →「查看」
- 分页（每页 10）

### 6. 确认/查看预警弹窗（`components/ConfirmAlertDialog.tsx`、`ViewAlertDialog.tsx`）

- 确认预警弹窗：预警依据 AI 卡片（账期+数值+判定条件说明）+「是否误判」单选（未误判/误判）+ 确认/取消；确认后行状态流转（未误判=绿、误判=红，记录确认人/时间）
- 查看预警弹窗：预警依据 + 确认信息（确认人/确认时间/是否误判）

### 页面详情

##### @page(/workspace/insight/alert/ai-monitor) AI指标监控预警列表

**核心职责**：规则配置与查看入口——按筛选/汇总形式浏览 AI 监控预警规则，新增规则、进入详情处理预警。
**访问路径**：工作台 → 洞察管理 → 预警管理 → AI指标监控预警；无必需参数。
**布局**：筛选栏（业务场景树选择、指标名称搜索框、展示形式下拉、重置/搜索、新增按钮）+ 规则表格 + 分页栏。
**列表项字段**：指标名称 / 业务场景（三级路径）/ 预警粒度 / 预警范围 / 当前判定条件（AI Badge）/ 准确率 / 误报次数 / 总预警次数 / 状态开关 / 操作（详情）

**交互说明**

| 元素 | 动作 | 响应 | 传参 | 备注 |
|------|------|------|------|------|
| 业务场景下拉 | 选择叶子场景 | 作为筛选条件 | — | 三级级联树 |
| 指标名称输入 | 键入 | 关键字过滤（点击搜索后生效） | — | — |
| 展示形式下拉 | 切换 不汇总/按指标汇总/按区域汇总 | 重组表格行 | — | 汇总列展示"N 个范围/N 个指标" |
| 重置 | 点击 | 清空全部筛选 | — | — |
| 搜索 | 点击 | 按条件过滤列表并回到第 1 页 | — | — |
| 新增 | 点击 | 打开新增弹窗 @modal(create-alert) | — | — |
| 状态开关 | 切换 | 更新规则启停状态 | — | 禁用时规则不产生预警 |
| 详情 | 点击 | 跳转 @page(/workspace/insight/alert/ai-monitor/detail)?id | id | — |
| 分页 | 切换页码 | 刷新当前页数据 | — | 每页 10 条 |

**弹窗 create-alert**：
- 标题："新增AI指标监控预警"
- 字段：业务场景（树选择必填）、预警粒度（省份/地市/区县/网格必填）、指标（可搜索下拉必填）、预警范围（随粒度联动下拉+搜索必填）
- 操作：确认（校验后插入列表首行）、取消

##### @page(/workspace/insight/alert/ai-monitor/detail) AI指标监控预警信息详情

**核心职责**：展示单条规则的指标基础信息与其各账期预警执行明细，并对待确认预警做确认处理。
**访问路径**：列表页操作列「详情」进入，携带 `id`；id 缺失或无效时提示后返回列表。
**布局**：返回按钮 + 标题 + 基础信息卡 + 预警情况表格 + 分页栏。
**列表项字段**：指标账期 / 指标数值 / 更新时间 / 判定条件（AI）/ 判定条件说明 / 是否执行指标预警（已执行未预警·绿、已执行已预警·浅红）/ 预警说明 / 是否误判（待确认·黄、未误判·绿、误判·红）/ 操作

**交互说明**

| 元素 | 动作 | 响应 | 传参 | 备注 |
|------|------|------|------|------|
| Logo/侧边导航 | 点击 | 离开详情页 | — | 全局导航 |
| 返回 | 点击 | 返回列表页（router.back） | — | — |
| 确认 | 点击（待确认行） | 打开确认预警弹窗 @modal(confirm-alert) | — | — |
| 查看 | 点击（已确认行） | 打开查看预警弹窗 @modal(view-alert) | — | — |
| 分页 | 切换页码 | 刷新明细数据 | — | 每页 10 条 |

**弹窗 confirm-alert**：
- 标题："确认预警"
- 内容：预警依据 AI 卡片（账期/指标数值/判定条件/说明）+ 是否误判单选（未误判/误判）
- 操作：确认（流转状态并记录确认人/时间）、取消

**弹窗 view-alert**：
- 标题："预警信息"
- 内容：预警依据（账期/数值/判定条件/说明/是否执行预警）+ 确认信息（确认人/确认时间/是否误判）
- 操作：关闭
