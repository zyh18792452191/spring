√ 营服运营平台

1.3 背景和现状

市场运营平台首页作为平台的统一入口，需要为运营人员提供一站式的数据监控和运营跟踪能力。当前存在以下问题：

  • 缺乏统一的数据总览入口，无法快速获取关键指标
  • 调度任务跟踪分散，无法实时掌握工单执行情况
  • 优秀运营案例未系统化展示，难以复用成功经验
  • 缺少业务口径说明，指标定义不清晰

1.4 价值评估

基于"数据驱动、实时监控、经验复用"的思路，实现以下目标：

  • 提升数据可见性：提供关键指标总览，支持业务口径说明，确保指标定义清晰
  • 提升监控能力：实时跟踪调度任务执行情况，监控全国及各省进度
  • 提升经验复用：系统化展示优秀运营案例，支持案例查看和参考
  • 提升用户体验：提供友好的导航和联系方式，确保问题及时得到支撑

2 业务流程

业务流程说明：

  1. 用户访问平台首页，系统加载指标总览数据
  2. 系统展示5个关键指标卡片：市场份额、价值保有、规模保有、渠道触客、业务订购/退订
  3. 用户鼠标悬停指标标签，系统显示业务口径说明
  4. 用户点击指标卡片，系统切换详情模块，显示该指标的不同维度数据和图表
  5. 用户切换详情模块的Tab，系统更新图表数据
  6. 系统加载调度跟踪数据，展示全国Top5和Bottom5指标
  7. 用户点击指标，系统查看该指标的趋势数据和活动详情
  8. 系统展示31省工单执行数据，包括工单总数、进行中工单、超时工单、完成率
  9. 系统加载优秀运营案例，展示案例标题、描述、标签、作者、日期
  10. 用户点击"查看更多"，系统跳转到案例广场页面
  11. 系统显示页脚信息，包括LOGO、导航链接、联系方式

3 营服平台需求

3.1 指标总览

3.1.1 指标卡片展示

• 功能说明

  1. 使用人员：一级运营人员、省级运营人员
  2. 支持操作类型：查看指标详情、查看详情模块
  3. 展示内容：
    • (1) 指标图标：显示在卡片左上角，根据指标类型显示不同图标（如TrendingUp、TrendingDown、Users、Wallet、Activity等）
    • (2) 指标标签：显示在卡片上方，简短描述指标含义（如"移动市场份额"、"价值保有率"等）
    • (3) 指标值：显示在卡片中央，数值形式展示（如"35.6"、"98.5"等）
    • (4) 指标单位：显示在指标值右侧（如%、万、元、户等）
    • (5) 环比趋势：显示在指标值下方，绿色表示增长，红色表示下降（如"+1.2%"、"-0.3%"、"-"等）
    • (6) 业务口径说明：鼠标悬停指标标签时显示，说明指标定义和计算方式
  4. 默认展示：展示5个指标卡片，按配置的顺序排列
  5. 数据刷新：系统每5分钟自动刷新数据，用户可手动点击刷新按钮强制刷新
  6. 数据格式：指标值格式化为千分位分隔符，保留2位小数

• 交互说明

  1. 鼠标悬停指标标签时，延迟200ms后显示业务口径说明Tooltip，鼠标移开后Tooltip立即消失
  2. 用户点击指标卡片，系统高亮显示该卡片（边框颜色为主题色，阴影加深），其他卡片恢复默认样式
  3. 系统在选中的指标卡片下方展开详情模块，同时间只能选中一个指标卡片
  4. 用户再次点击已选中的指标卡片，系统取消选中状态，关闭详情模块
  5. 系统每5分钟自动刷新数据时，显示加载动画，刷新完成后显示成功提示

• 约束规则

  1. 首页最多展示5个指标卡片，超出部分不展示
  2. 同时间只能选中一个指标卡片
  3. 指标值格式化为千分位分隔符，保留2位小数
  4. 环比趋势为0时显示灰色"-"，不显示增减颜色
  5. 数据刷新失败时显示错误提示，并支持重试
  6. 业务口径说明最多200字符，超出部分截断显示

• 界面设计

卡片采用渐变背景，左侧为彩色渐变，右侧为白色背景，卡片宽度固定220px，高度120px，圆角8px，hover时阴影加深，详情模块默认隐藏，选中指标卡片后展开显示，宽度100%，高度自适应，最大高度600px

3.1.2 指标详情模块

• 功能说明

  1. 使用人员：一级运营人员、省级运营人员
  2. 支持操作类型：切换Tab、查看图表、查看数据表格、导出数据
  3. 展示内容：
    • (1) 模块标题：显示当前选中的指标名称（如"市场份额"）
    • (2) Tab切换：默认展示2个Tab（全国数据、省份数据），可配置更多Tab
    • (3) 图表区域：根据选中的Tab显示对应的图表（饼图或柱状图）
    • (4) 数据表格：图表下方显示详细数据表格
  4. 图表类型：全国数据Tab显示饼图，省份数据Tab显示柱状图

• 交互说明

  1. 用户点击Tab，系统切换高亮显示（颜色为主题色），其他Tab恢复默认样式
  2. 系统根据Tab类型查询对应的图表数据，图表切换时显示加载动画
  3. 用户点击表格表头，系统按该列升序/降序排列数据
  4. 用户点击"导出"按钮，系统下载Excel文件
  5. Tab切换时保留上一个Tab的状态，返回时无需重新加载数据

• 图表展示规则

  1. 全国数据Tab：
    • (1) 显示饼图，展示三大运营商（移动、电信、联通）的指标占比
    • (2) 饼图扇区颜色：移动绿色（#10b981）、电信蓝色（#3b82f6）、联通橙色（#f59e0b）
    • (3) 显示数据标签：运营商名称+百分比，保留1位小数
    • (4) 显示图例：右侧对齐，显示运营商名称和颜色
  2. 省份数据Tab：
    • (1) 显示柱状图，展示31个省份数据
    • (2) 横轴为省份名称（简称，如北京、上海、广东）
    • (3) 纵轴为指标值，自动根据最大值设置刻度
    • (4) 柱状图颜色：根据指标配置的主题色
    • (5) 显示数据标签：柱状图顶部显示数值，保留2位小数
    • (6) 支持横向滚动：数据量多时支持横向滚动查看

• 约束规则

  1. 每个指标最多配置5个Tab
  2. 全国数据最多包含3个运营商
  3. 省份数据包含31个省份数据
  4. 图表数据至少有1条记录，否则显示"暂无数据"提示
  5. 数据表格支持分页显示（每页10条）

• 界面设计

Tab导航位于模块顶部，横向排列，字体14px，图表区域位于Tab下方，高度400px，数据表格位于图表下方，支持分页显示（每页10条）

3.2 调度跟踪

3.2.1 全国指标展示

• 功能说明

  1. 使用人员：一级运营人员、省级运营人员
  2. 支持操作类型：查看指标详情、切换Tab（Top5/Bottom5）、查看活动列表
  3. 展示内容：
    • (1) 模块标题：全国指标跟踪
    • (2) Tab切换：Top5指标、Bottom5指标两个Tab
    • (3) 指标列表：根据选择的Tab展示对应的指标列表
    • (4) 指标详情：点击指标后在右侧展示指标详情
  4. 默认状态：默认选中Top5指标Tab，显示改善幅度最大的5个指标

• 交互说明

  1. 用户点击Top5指标Tab，系统切换高亮显示，显示改善幅度最大的5个指标
  2. 用户点击Bottom5指标Tab，系统切换高亮显示，显示改善幅度最小的5个指标
  3. 用户点击指标列表项，系统高亮显示该项，右侧显示该指标的详细信息
  4. 同时间只能选中一个指标，右侧详情实时更新

• 指标列表展示规则

  1. 列表项展示：指标名称、当前值、改善幅度、活动数量、工单总数
  2. 当前值根据改善幅度显示颜色（增长绿色，下降红色）
  3. 改善幅度格式："+x.x%"或"-x.x%"
  4. 活动数量显示该指标关联的活动数量
  5. 工单总数显示该指标关联的工单总数

• 指标详情展示规则

  1. 点击指标列表项，右侧展示详细信息：指标名称、当前值、改善幅度、活动数量、工单总数、趋势图表（最近6个月）、活动列表（最多8个活动）
  2. 趋势图表：折线图，横轴为月份，纵轴为指标值
  3. 活动列表：展示活动名称、活动时间、执行状态、触达客户数
  4. 活动列表超出8个，显示"查看更多"链接

• 约束规则

  1. Top5和Bottom5各显示5个指标
  2. 趋势数据包含最近6个月的数据
  3. 活动列表最多显示8个活动，超出部分通过"查看更多"跳转
  4. 同时间只能选中一个指标
  5. 数据刷新间隔为5分钟

• 界面设计

模块采用左右分栏布局，左侧列表宽度40%，右侧详情宽度60%，列表项采用卡片式布局，高度60px，支持hover效果，趋势图表高度250px，活动列表高度300px，支持滚动

3.2.2 31省工单数据展示

• 功能说明

  1. 使用人员：一级运营人员、省级运营人员
  2. 支持操作类型：查看省份详情、排序、搜索、刷新、导出
  3. 展示内容：
    • (1) 模块标题：31省工单执行情况
    • (2) 搜索框：支持按省份名称搜索（模糊搜索）
    • (3) 统计栏：表格上方展示汇总数据（工单总数、进行中工单数、超时工单数、平均完成率）
    • (4) 表格：展示31省的工单执行数据

• 交互说明

  1. 用户输入搜索关键词后，表格实时过滤显示匹配的省份
  2. 用户点击表头，系统按该列升序/降序排列数据
  3. 用户点击"刷新"按钮，系统重新查询最新数据，显示加载动画
  4. 用户点击"导出"按钮，系统下载Excel文件
  5. 用户点击"查看详情"按钮，系统跳转到该省份的工单详情页面

• 表格列说明

  1. 省份：省份名称（简称），支持点击查看详情
  2. 工单总数：该省份的工单总数，数字格式
  3. 进行中工单：正在执行的工单数量，蓝色字体
  4. 超时工单：超时未完成的工单数量，红色字体
  5. 完成率：工单完成百分比，格式"x%"，根据完成率显示颜色（≥90%绿色，≥80%黄色，<80%红色）
  6. 操作：点击"查看详情"按钮，跳转到该省份的工单详情页面

• 约束规则

  1. 工单总数、进行中工单数、超时工单数必须大于等于0
  2. 完成率必须为0-100之间的数值
  3. 表格展示31省数据，支持分页（默认每页10条）
  4. 数据刷新间隔为5分钟
  5. 搜索支持中文省份名称和简称

• 界面设计

表格固定表头，支持纵向滚动，搜索框位于模块右侧，宽度200px，统计栏位于模块顶部，横向排列4个统计卡片，表格采用斑马纹样式，hover高亮显示

3.3 优秀运营案例

3.3.1 案例展示

• 功能说明

  1. 使用人员：一级运营人员、省级运营人员
  2. 支持操作类型：查看案例详情、跳转到案例广场
  3. 展示内容：
    • (1) 模块标题：优秀运营案例
    • (2) 案例列表：横向排列3个案例卡片
    • (3) 查看更多按钮：跳转到案例广场页面
  4. 默认展示：按案例日期降序排列，取前3个案例

• 交互说明

  1. 用户点击案例卡片，系统跳转到案例详情页面
  2. 案例详情页面展示案例标题、封面、详情内容、作者、日期、相关推荐案例
  3. 用户点击"查看更多"按钮，系统跳转到案例广场页面

• 案例卡片展示规则

  1. 案例封面：显示在卡片顶部，宽度100%，高度160px，圆角8px
  2. 案例标题：显示在封面下方，字体16px，加粗，颜色#334155，最多显示2行，超出显示省略号
  3. 案例描述：显示在标题下方，字体14px，颜色#64748b，最多显示3行，超出显示省略号
  4. 案例标签：显示在描述下方，横向排列，每个标签为胶囊样式，背景色#f1f5f9，文字颜色#475569，字体12px
  5. 案例作者：显示在底部左侧，字体12px，颜色#94a3b8，格式"作者：XXX"
  6. 案例日期：显示在底部右侧，字体12px，颜色#94a3b8，格式"YYYY-MM-DD"

• 约束规则

  1. 首页最多展示3个案例
  2. 案例按日期降序排列，最新的案例排在最前面
  3. 案例卡片高度固定240px，超出内容截断显示
  4. 案例标签最多显示3个，超出部分隐藏
  5. 封面图片支持懒加载，加载失败时显示默认占位图

• 界面设计

案例卡片宽度固定340px，高度240px，卡片采用白色背景，圆角8px，阴影效果hover时加深，封面图片支持懒加载，查看更多按钮位于模块右侧，链接样式

3.4 页脚

3.4.1 页脚展示

• 功能说明

  1. 使用人员：所有用户
  2. 支持操作类型：点击导航链接、点击联系电话、点击联系邮箱
  3. 展示内容：
    • (1) 平台LOGO：显示在页脚左侧，宽度200px，高度60px
    • (2) 平台名称：显示在LOGO右侧，字体18px，加粗，颜色#334155
    • (3) 导航链接：显示在平台名称右侧，横向排列，间距20px，字体14px，颜色#64748b，hover时颜色变为主题色，包括平台介绍、操作手册、常见问题
    • (4) 联系方式：显示在页脚右侧，纵向排列，字体14px，颜色#64748b，包括联系电话、联系邮箱

• 交互说明

  1. 用户点击导航链接，系统在当前标签页打开对应页面
  2. 用户点击联系电话，移动端触发tel协议拨号，PC端不做特殊处理
  3. 用户点击联系邮箱，系统触发mailto协议打开邮件客户端

• 约束规则

  1. 页脚固定在页面底部，高度80px
  2. 所有内容居中对齐，左右边距40px
  3. 导航链接在新窗口打开（可配置）
  4. 联系方式展示顺序：联系电话、联系邮箱
  5. 移动端隐藏导航链接，只显示LOGO、平台名称和联系方式

• 界面设计

页脚采用浅灰色背景（#f8fafc），宽度100%，内容横向排列，左侧为LOGO和平台名称，中间为导航链接，右侧为联系方式，响应式设计，移动端隐藏导航链接

4 数据说明

4.1 指标总览数据

• 接口名称：查询指标总览

• 请求字段：用户ID

• 返回字段：指标ID、指标名称、指标图标、指标值、指标单位、指标标签、业务口径说明、环比趋势、指标颜色

4.2 指标详情数据

• 接口名称：查询指标详情

• 请求字段：指标ID、Tab类型（全国/省份）

• 返回字段：指标名称、Tab类型、全国数据（运营商名称、指标值、单位、占比、环比）、省份数据（省份名称、指标值、环比、排名）

4.3 调度跟踪数据

• 接口名称：查询调度跟踪指标

• 请求字段：用户ID、指标类型（Top5/Bottom5）

• 返回字段：指标ID、指标名称、当前值、改善幅度、活动数量、工单总数、趋势数据（月份、指标值）、活动列表（活动ID、活动名称、活动时间、执行状态、触达客户数）

4.4 31省工单数据

• 接口名称：查询31省工单数据

• 请求字段：用户ID

• 返回字段：省份编码、省份名称、工单总数、进行中工单数、超时工单数、完成率、汇总数据（工单总数、进行中工单总数、超时工单总数、平均完成率）

4.5 优秀案例数据

• 接口名称：查询优秀案例

• 请求字段：用户ID

• 返回字段：案例ID、案例标题、案例描述、案例标签、案例作者、案例日期、封面图片URL

4.6 平台配置数据

• 接口名称：查询平台配置

• 请求字段：无

• 返回字段：平台LOGO、平台名称、导航链接（链接名称、链接地址）、联系电话、联系邮箱
